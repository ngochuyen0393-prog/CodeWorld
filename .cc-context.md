## core API（已确认，直接用）
- `WorldState { entities: HashMap<EntityId, Entity>, zones: HashMap<ZoneId, Zone>, transforms: Vec<TransformEntry> }`
- `Entity::pos() -> (f64,f64)` / `set_pos(&mut self, (f64,f64))` / `appearance: Appearance` / `id: EntityId`
- `EntityId(pub Uuid)`
- `BoundingBox::new(x_min,y_min,x_max,y_max)` / `contains(x,y)->bool`
- `Zone::new(owner: PlayerId, bounds, rules_code_hash: String, created_tick: u64)` / `{ id, owner, bounds, transform, rules_code_hash, created_tick }`
- `TransformEntry::new(owner: EntityId, scope: TransformScope, transform_fn: Vec<u8>, priority: i32, created_tick: u64)` / `{ id, owner, scope, transform_fn, priority, created_tick }`
- `TransformScope: Entity(EntityId) | Zone(ZoneId)`
- `VisibleEntity::new(id, pos, appearance)`

## 设计决策
- SpaceEngine/TransformPipeline/ZoneManager **无状态**（new() 创建空结构，方法接收 `&WorldState`/`&mut WorldState`）。状态都在 WorldState。
- `TransformFnExecutor` trait 抽象 WASM 执行，MVP `IdentityExecutor`（恒等）。`apply_transforms` 接收 `&dyn TransformFnExecutor`。
- `get_transforms_for_entity` 按 scope 过滤（Entity 匹配 id；Zone 匹配实体所在 zone）+ priority 降序排序。
- `apply_transforms` 内部按 priority 降序排序后 fold 应用（健壮，不依赖输入顺序）。
- `SpaceError`(thiserror)：EntityNotFound。`set_entity_pos` 返回 Result。

## 数据流
```
坐标读写：SpaceEngine.get_entity_pos/set_entity_pos -> WorldState.entities
视口查询：get_visible_entities -> 过滤 entities 坐标在 BoundingBox 内 -> VisibleEntity
变换：register_transform -> WorldState.transforms.push；apply_transforms -> 按 priority 降序 fold(executor.execute)
区域：register_zone -> WorldState.zones.insert；find_zones_at -> 过滤 bounds.contains；entity_in_zone -> entity.pos 在 zone.bounds
```
