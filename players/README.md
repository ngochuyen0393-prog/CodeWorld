把你的 `.wat` 文件放进本目录即进场（一个文件 = 一名玩家，接口见 `docs/api.md`），删除文件即下线；`_template.wat.txt` 是模板（不会被启动）——想用就复制一份改名成 `<你的名字>.wat`。`_` 前缀文件与 `.txt` 后缀不会被当玩家加载。

## 操控自己的角色：me.txt（decisions.md #024）

在 `players/me.txt` 里写一行你的玩家名（如 `pioneer`，等价地设环境变量 `CODEWORLD_ME`，优先级更高），世界就会把你的键盘输入路由给这个角色：WASD/方向键移动、空格攻击、q 退出。名字必须对应已进场的在线玩家——拼错或没进场就是**观战模式**（画面照常，字幕显示 `ctrl:--`，按键不动任何角色，日志有一次 warn）。操控中删掉玩家文件 = 角色下线，自动转观战，重新放进文件**不会**自动恢复操控（需重启世界）。

## 一格一物：撞上就是被挡（decisions.md #021）

世界是占位制：每个格子只能站一个存在。你的移动目标格被人（或你自己的造物）占着，这拍就原地不动（日志有"移动被挡"记录，下拍可重试）；spawn 的出生格被占，那次造物直接失败（不诞生，下拍可重试）。`pioneer.wat` 是现成范本：立塔造在 +5 格、立塔那拍不移动——刚进场就把自己堵死是拓荒常见事故。

## 想要超视距情报？造个哨塔

框架不给任何超视距坐标（decisions.md #018）——哨兵网络是正解之一：在自己代码里用 `env.spawn` 把 `examples/sentinel.wat` 造到身边，它有人过境就会发观察信号 `log(2)`（运行日志 `[player_log] marker=2` 行）。造物是活实体：跑自己的代码、生死自己决定，与你的在线状态无关；出生点限你坐标 ±10 格，出生格被占则造塔失败（别造在自己站的格上），世界实体上限 64。

最小造物调用见 `docs/api.md` 的 `spawn` 条目；销毁自家造物用 `env.destroy`（无掠夺）。
