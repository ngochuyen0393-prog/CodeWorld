把你的 `.wat` 文件放进本目录即进场（一个文件 = 一名玩家，接口见 `docs/api.md`），删除文件即下线；`example.wat` 是第一个玩家模板。

## 想要超视距情报？造个哨塔

框架不给任何超视距坐标（decisions.md #018）——哨兵网络是正解之一：在自己代码里用 `env.spawn` 把 `examples/sentinel.wat` 造到身边，它有人过境就会发观察信号 `log(2)`（运行日志 `[player_log] marker=2` 行）。造物是活实体：跑自己的代码、生死自己决定，与你的在线状态无关；出生点限你坐标 ±10 格，世界实体上限 64。

最小造物调用见 `docs/api.md` 的 `spawn` 条目；销毁自家造物用 `env.destroy`（无掠夺）。
