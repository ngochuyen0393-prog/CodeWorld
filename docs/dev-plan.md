### D-005 决斗制攻杀 [设计稿 v0.2·待拍板 5 题]（docs/design-duel.md，2026-10-18）
- 骨架定案（土豆多轮拷问定稿）：**世界只当硬件不当刽子手**（换血退役）；**守方全内存皆战场**（无角斗场，命中=内存映射直连，攻方直接读写守方内存，中间无世界代码）；**引擎不可改改魂等效**（操纵比杀死值钱）；**死亡靠断不靠改**（四条死路全机械化：life 自断/崩溃/燃料尽/点数尽，扣扳机的永远是自己的机器）；**驾驶者免疫夺舍可被污染信息源**。
- 攻击链语法：弹丸=游魂的机票（身体负责抵达）→命中=登陆→游魂=进门后的战斗员（灵魂负责征服）→战果谱：夺舍（傀儡是资产）/偷魂/耗魂/击杀/驱逐。状态谱：健康>傀儡>死亡。
- 燃料双重身份法：日常=步数保险丝（禁入玩法不变），攻防会话内=兵力（攻方弹丸出厂携带/守方本体+插件余额）。
- 居民四形态：本体（连接器+插件）/造物（儿）/游魂（攻击形态）/布景。插件=无身器官随本体死，造物=独立生死，游魂不能独立发射（通信自由注入无门）。
- 待拍板 5 题：守方可见性三档/偷魂带走什么/燃料赌注数值/夺舍确权 N 拍/决斗并发上限。
- 待拍板后展开任务书，宪法级大刀双审+旗舰模型；先最小原型（裸奔特例回归锚定）。

### D-006 插件化本体架构 + 零代码玩家路线 [已定方向·排决斗制之后]（2026-10-18）
- 世界观定位（土豆顿悟）：**整个架构源自 Pi/DSH——世界=对抗性 agent 宿主，玩家=agent/插件，宪法=运行时契约**。Pi/DSH 是通用 agent 宿主，我们是对抗性 agent 宿主（agent 间可攻杀/掠夺/夺舍——独有维度）。开源叙事升级：不是开源一个游戏，是开源一个对抗性 agent 世界引擎（无竞品，调研定论投递+决斗链路无先例）。
- 插件化：本体=极小连接器（BIOS，永不可改）+插件沙箱们（行为器官：战斗/防御/求生/听鼠标）。器官与子孙之分：插件随本体死，造物独立生死。攻防含义：插件成为主战场（换装/改魂/拔除），"改引擎"死结解开（模块替换本来是合法操作，攻击只是未经同意地做了一次你能自己做的事）。
- 零代码玩家：模板生态（WC3 验证路线：不写代码的活法由其他玩家供给——现成生物/防御模块/行为包）+驾驶台阶（操控本体玩→想自动化某动作=写第一行代码的时刻）。世界预置求生本能=违宪入否决档案。
- 排期：决斗制（D-005）之后——夺舍换插件要等插件存在。

### D-009 水体系统：布景+浮力物理域 [已定案·挂信号]（2026-10-18，海底造物过条产出）
- 决策：水体走**布景层+规则层分离**（A+B 路线已拍：世界生成器按种子出水域布景+官方以玩家身份造示例活水）。浮力=物理域（体积传感器+阿基米德+附加阻尼，业界标准自写），**不做守恒水体**（水不流动不搬运——MC 1.13 液体卡顿/Terraria 强制 settle 的教训：守恒是自我加码，布景水下一切免费）。
- 海底造物=验收项：水下悬浮平衡（浮力对重力）+落底支撑（地面钳制换湖底面）+水下实体双件套（阻力域+呼吸条，Terraria 先例——呼吸条是否进玩法待定，倾向先只做阻力域）。
- **水中物理账（2026-10-18 过条补全）**：游泳=竖直方向浮沉游戏（重力 vs 浮力，密度定命运：轻漂/重沉/近似鱼悬浮，全自动结算零代码要求）；踏水=水平推阻游戏（推力 vs 水阻），竖直方向被浮力免费补贴（体重被托走）——"轻功水上漂"=真正的玩家代码手艺（每拍输出推力对抗水阻+控制密度停水面，出力耗 fuel）。
- **两栖困境=生态分化（零预设涌现）**：专化陆生（沉底爬行）/专化水生（上岸难）/两栖（带调密度结构——潜艇原理，两头都不是最强）/造物替身（本体在岸，水下派探测器，产权风险）。没有免费的两栖——物理定律自然长出的生态位。
- **浮力代码的边界（2026-10-18 定案）**：浮力代码本质="当我在水里怎么办"的条件反应（不是施法）——陆地上浮力项=0，定律在值为空，代码无事发生（不报错；但只写水中逻辑没探测切换的会在岸上空烧 fuel 踩水=诚实的代价）。**感知环境→切换行为=玩家代码通用范式**（scan 探测水域→水中/陆地模式切换；将来力场/天气/岩浆同招）。状态机是玩家的功课：岸上/入水/半沉/全浸没/出水五态全自己写。
- 调研定论（2026-10-18 勿再查）：WC3 水面纯视觉+寻路独立/Screeps swamp=地形标记改移动成本——布景+规则分层双先例；Factorio 悬崖与水=装饰性碰撞（拍制世界选静态地形的理性决策）；RimWorld 支撑规则最简版（屋顶距支撑 6 格塌）留作地层时代参考；挖掘=格子整数变更天然可复现，与零预设宪法无冲突（能力接口语义）。
- 信号：液体玩法需求出现（沼泽战术/水路运输/岩浆护城河任一）。

### D-008 3D 升维 + 形状物理包 [路线图定案·挂信号]（2026-10-18 土豆拍板：确定做 3D）
- 定案：**2D 是婴儿期，3D 是既定方向**（土豆 2026-10-18 明确"我们肯定不是要做 2D 游戏"）。升级路径宪法早已预留（#030）：连续坐标+半径 → 3D=圆变球、方块变立方体的公式升维，**不需要拆迁**。
- 形状物理包（土豆同日扣动扳机："其他形状呢，异型的呢"）：**形状（异型）+密度（材料）+旋转（惯性）+碰撞响应（弹/摩擦）四位一体**一刀齐。调研定论（勿再查）：旋转有物理意义的形状=长杆（摆锤武器/Hammerfight）/方块复合体（塌落/Angry Birds/Besiege）/异型（Noita 多像素复合刚体）；公式抄 Box2D 偏心冲量（j_n=-(1+e)(v·n)/(1/mA+1/mB+(rA×n)²/IA+(rB×n)²/IB)→ω+=r×j/I），**确定性必须写进验收**（Poly Bridge 1 因 Box2D 非确定性 2/3 代重写自研引擎的先例）。
- **地层系统与 3D 同刀**（2026-10-18 水体调研追加定论）：地面从线变体（2D 格子矩阵）本身不贵（Terraria/RimWorld 同构），贵在挖掘管线+支撑规则+存档膨胀，且 2D 地层做完升 3D 大概率重做——**与 3D 同刀决策，避免白做**。地底造物（地道战/藏库/地下城）=地层+支撑语义的玩法层，本质第三维战术=3D 议题，随 3D 走。
- 路线图因果链：拍速升级 5-10/s（已定方向）→ 3D 升维（三轴旋转：俯仰/偏航/横滚，质心成空间点）+地层同刀 → 形状物理包 → 捏形状玩法（城/龙/机械——玩家创造完全体，"捏一条会翻滚的龙"要求包+3D 同时到位）。
- 信号：3D 切换=拍速升级落地后+玩家视觉成熟时（土豆若有异议随时改）；形状物理包=捏形状系统立项（与密度/物理旋转共用信号）。

### D-010 冲量与出力系统 [已定案·挂信号]（2026-10-18，菜单 1.2 过条产出）
- 三件套：**碰撞冲量**（撞=停→撞=动量交换：restitution 弹性+friction 摩擦，公式抄 Box2D 标准带质量比，**确定性写进验收**）+**攻击冲量**（击退 payload：被击中者吃一记冲量，方向=攻击来向；时序契约已定案——同拍击飞先于投递→按实况落空）+**自主出力**（thrust(dx,dy) API：本拍给自己一记冲量，耗 fuel——跳跃/踏水推进/轻功水上漂的地基）。
- **#021 切割声明（立法时必须显式写）**：已退役的"推挤"（持续重叠互相挤开→连体 bug）≠冲量（碰撞瞬间一次性动量交换，撞完就分）——立法文档显式切割防混淆。
- API 边界：**力出自己身**——只开 thrust 给 self，不开放"推别人"API（推人走碰撞或击退 payload，与"攻击形态归玩家"同哲学）。
- 击退×决斗交互（2026-10-18 定）：**击退不中断决斗，会话跟身体走**（沙箱长在实体上，飞到哪打到哪）；多游魂并存见 design-duel 九B 条款。
- 参数锚点（1.7 标定法）：restitution 0~1（撞一下弹开半格观感）/friction 0~1（冰面滑三格草地面即停对比）/thrust 上限（单次跳跃≤3 格高）/出力燃料系数（满力一次≈5%fuel）。
- 拆刀建议：**冲量小刀**（thrust+跳跃，纯增益，可先做）→**碰撞响应刀**（撞=弹+#021 切割+确定性锚）→击退 payload 随决斗制。
- 信号：冲量小刀=拍速升级前任意时点（跳跃机动需求）；碰撞响应刀=决斗制落地后（击退 payload 依赖新投递语义）。

### D-012 力场系统：玩家可调制物理参数场 [已定案·挂信号]（2026-10-19 菜单 1.2 力场过条，土豆多轮拷问定稿）
- **定义**：场=造物的一种出生声明（field 参数家族：有/半径/改哪个参数/改成多少，与 radius/mass/binding/motion 并列）——**"场造物"作为特殊品类在法律上不存在**，世界只认声明不认身份。场源=物理身体（大小自由声明，效果以身体为锚向外延伸），效果=参数改写区（无形体不占位）。
- **运行模板**（持续效果标准模板第三例，与悬停/游魂同构）：一次声明+每拍世界核实（"场还在吗"一次沟通几步的事）+失联即恢复默认。**零特殊计费**（土豆否决收费案：负载费=防守方因被攻击而破产的荒谬；底租=世界给玩法定价违 #011）——场的成本=普通造物日常开销+实体名额。
- **叠加三规则+收敛**：同参数取最强/不同参数各管各/冲突按优先级（同优先级按 EntityId 定序）——UE PhysicsVolume Priority+DOTA2 同名取最强判例。多场收敛不混乱：身体不叠+参数槽有限+取最强去冗余；自伤真实（场不认人，豁免是场代码自己写的=表达自由）。
- **三条地基法律显式化**（2026-10-19）：①接触=物理身体碰撞（效果无形永不相撞）；②沙箱投影=身体（沙箱无大小，身体有大小，攻击打的是身体）；③身体不可重叠/效果可重叠/攻击接触只认身体。效果大于沙箱≠巨人问题——判据是"所见与所判一致"（场可视+真实物理作用+身体 telegraphing，两端诚实）。
- **攻防预期（全部已有法律组合，零新法）**：场反制五路（经济耗名额/物理强攻——重弹怼阻力·高弧越顶·近战贴脸不受弹道场影响/夺舍场源/对冲场/耗到自灭）；全场化买不到免疫（效果不拦截碰撞，隐藏只买到"难找"）；透明战术=合法防御纵深（骗人眼不骗 probe——probe 触发应答博弈：沉默/伪装/伪造是应答方代码的本事，视觉透明只是最外层的皮）；隐藏=情报问题不是判定问题。
- **判例采纳**（2026-10-19 调研定论勿再查）：0.1s tick 刷场（DOTA2 冰女，比 enter/exit 鲁棒）为实现底座；成型时间给进攻反应窗（Kinetic Field 1.2s）；场必须可视（温迪气流环范本——纯数值场配贴地特效）；边界触发单位级冷却防抖（Veigar 4.5s）；施法者豁免=代码自写非世界默认；**距离衰减是同行空白区=咱们独占设计位**（强度∝距场源衰减，天然解决叠加仲裁）。反面教材：Unity WindZone 只吹树不推刚体（同行的场多是假物理=咱们差异点）；WoW 图腾 5HP 一击碎是 20 年怨案（可摧毁场要给足耐久——咱们版本更妙：反制场=反向入侵改参数，不是打血条）。
- **实施提示**：极端参数边界跳变是渲染层平滑问题（前端渐变），非规则漏洞。
- 信号：决斗制落地后（场反制的夺舍路依赖通道互授）；菜单 1.2 收官条目。

### D-011 链路系统：造物的活链 [已定案·随活弹同期]（2026-10-18 土豆三件套定案）
- 本体与飞出造物（飞剑/机械蜂/侦察弹）**链接不断**：①控制链（command(造物id,指令)——飞行轨迹/转弯，飞剑剑诀）②数据通道（外接算力/数据回传——外桥覆盖弹丸沙箱，立法确认）③信息存储块（造物=移动硬盘，信息通道存储转发）。
- 链三态：无链（放生，现状默认）/活链（可控+可传）/断链（被掐或主动断→孤儿按 unbound 契约活）。**link=binding 家族新成员**（与 #035 契约互补：契约=出生遗嘱，控制=活电话）。
- 依赖：通道公理（design-duel 十一节）——控制指令=信息通道消息，反杀=沙箱通道双向互授。
- 玩法预期：风筝流（活链遥控+情报回传）↔ 反杀对称（守方反手夺舍飞剑——"放风筝的人自己也在被钓"）；俘获代码段=驯服敌方生物（副本装进自己造物）；OODA 循环（侦察弹→外脑→定制弹）。
