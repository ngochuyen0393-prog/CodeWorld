# 游戏系统菜单（六游戏交叉调研 · 完备性清单）

> **用途**：回答"一个成熟游戏由哪些系统组成"。新玩法立项前扫一遍对应层，防"想起一个写一个"；每刀收尾顺手更新状态列。
> **调研定论（2026-10-17，勿再重复调研）**：Screeps / Factorio / Minecraft / 魔兽世界 / 魔兽争霸3 / 原神 六家系统全景，六路子代理带出处调研 + gamerule 官方 wiki 全表补齐。
> **宪法对齐**：本菜单是完备性清单 + 研究索引，不是功能愿望清单。每项立项前过两道门：①"改变世界提供的能力吗"测试（#011 能力vs规则）②"有消费者吗"测试（立法立因不立果）。

## 0. 六家独门速查（每家对我们最值钱的一样）

| 游戏 | 独门贡献 |
|---|---|
| Screeps | 唯一同门师兄：意图结算模型（读旧快照→提交意图→拍末统一结算+优先级解冲突，与我们两阶段管线同构）；算力即资源（CPU bucket 攒算力/爆发/兑换）；RoomVisual=玩家代码在世界里画图不计 CPU——我们"玩家造物视觉自绘"路线的先行验证 |
| Factorio | 拍制模拟工业级全件套：chunk 休眠省算力；确定性（同种子同输入同结果）+replay 回放；污染系统="玩家行为→环境累积→环境反作用"闭环范本；电路网络=零代码版玩家编程（与我们"玩法归玩家"同构品） |
| Minecraft | gamerule=字面意义的规则菜单（Player/Mobs/Spawning/Drops/World/Chat/Misc 七类全表，见附录）；模拟距离与视野距离分离（世界算多远≠客户端看多远）；随机 tick 抽样更新（不为每棵草每拍付钱） |
| 魔兽世界 | 20 年 MMO 运营件：仇恨表（确定性数值，远程 130%/近战 110% 拉仇恨阈值）；attack table 一次掷骰有序结算；phasing/sharding/layering 位面三件套；Lua 全开放 UI——默认 UI 本身就是插件（架构参考） |
| 魔兽争霸3 | "玩法归玩家"祖师爷：触发器 ECA（事件-条件-动作）→JASS 双层设计，玩家从搭积木自然过渡到写代码；对象编辑器把一切内容数据字段化；地图即完整游戏，按图分发零门槛（DotA 由此长出） |
| 原神 | 元素量计（状态效果=可计量资源：附着量+线性衰减+按克制比消耗，仅七元素组合表+三条定律涌现全部配合——"立因不立果"教科书）；伤害乘区严格分离（任何增益只进一个乘区）；天气=环境状态源（雨天自动附水元素参与反应网）；打击感标准件 |

## 1. 规则层（世界怎么结算）

### 1.1 攻击与命中

| 项 | 谁有 | 是什么 | 状态 | 信号/备注 |
|---|---|---|---|---|
| 攻击形态三派 | 战地/原神/Screeps | 射程判定派/动画体积派/弹道派 | ✅ | 双轨定案：近身瞬发接触判定 + 远程弹丸（#034）；大作品不选边，攻击形态归玩家 |
| 防穿透 CCD | — | 拍内线段扫掠 | ✅ | #034 修订二已落地；与限速解耦（三件事各走各的） |
| 速度上限 | MC 矿车速/gamerule | 可调世界极速 | ✅ | CODEWORLD_MAX_SPEED=视觉可读性常数（#034 修订一），MC 同型做法验证方向 |
| 伤害类型×抗性矩阵 | Factorio 8 类伤害+两段式抗性公式；魔兽3 攻击类型×护甲类型系数表 | 数值伤害的结算表 | 🚫 | 我们攻击只伤代码与算力，无 HP 数值伤害（宪法攻击语义）；玩家要"抗性"自己写防御代码 🔵 |
| 命中判定链 | WoW attack table（miss/招架/躲闪/格挡/暴击一次掷骰有序表，闪避堆满可把命中挤掉） | 随机命中裁决 | 🚫 | 我们零随机（EntityId 定序消随机，#030）；确定性是我们对玩家的诚实承诺 |

| 攻击预告 telegraphing | 原神前摇/锁定时机；极速常数的立法动因 | 攻击必须可读可反制 | ✅ | 已内含在世界极速立法里（#034）；"已起手不换目标"型确定性 AI 规则若做原生生物时参考 |
