## 第 1 章 物理系统（Physics）——世界自然法则

> 业内标准目录来自 Box2D / Rapier / PhysX 三大物理引擎的通用结构。拍制世界（我们/MC/Factorio/Screeps）与实时物理世界（60Hz）共享同一套概念，只是求解频率不同。
> 词条五件套：白话（是什么）/ 管什么（在世界里的作用）/ 动它会怎样（影响）/ 业内标准 / 咱们。

### 1.1 基本量（Body Properties）——东西的"身份属性"

#### 刚体三类型 static / kinematic / dynamic 🟡
- 白话：世界里的东西分三种身份——钉死的（地面的墙，永远不动）、被剧本拽着走的（电梯，不靠力靠指令挪位置）、完全活的（扔出去的石头，一切交给物理算）。
- 管什么：决定每样东西"听谁的"——听物理定律的、听脚本指挥的、还是谁的话都不听。
- 动它会怎样：身份定错行为全乱——把墙错设成"活的"，撞一下墙就被撞飞了。
- 业内标准：一切物理引擎的第一课（static/kinematic/dynamic 三分类）。
- 咱们：动态实体+静态造物已有；中间那类（脚本驱动不受力）还没分出来。

#### 质量 mass / 密度 density ✅
- 白话：东西有多重。一样大的力推，轻车窜出去、重车纹丝不动。
- 管什么：重的东西难加速也难停下；飞行物被阻力拖拽的程度也跟它挂钩（越重越拖不动）。
- 动它会怎样：没有质量，万物手感一样轻飘飘；但质量一旦参与伤害计算，物理和胜负就搅在一起了——这是咱们的宪法禁区。
- 业内标准：引擎按形状×密度自动算（Box2D/Rapier）；原神怪物有隐藏重量值，只影响被打飞多远、不影响伤害——和咱们同款立法。
- 咱们：✅ mass 已立法：只参与物理反应（弹道/击退），永不参与攻击结算（#033）。

#### 质心 / 旋转惯性 center of mass / inertia ⬜
- 白话：物体"绕着哪一点转"（质心）和"多不愿意转起来"（惯性）。
- 管什么：东西翻滚起来像不像真的——轮胎会滚、冰块只会滑。
- 动它会怎样：没有它，东西只能平移不能打转。
- 业内标准：引擎按形状自动算。
- 咱们：无旋转系统，暂不需要。

### 1.2 通用力（Forces）——世界里的"隐形之手"

#### 重力 gravity ✅
- 白话：把一切往下拉的常力，就是地球吸万物那个。游戏里它是个数字，不是真理。
- 管什么：世界有"上下"的概念——飞行物的弧线、跳跃的回落、掉落的加速，全由它画出来。
- 动它会怎样：调大=万物沉重砸得飞快（真实 9.8 抄进咱们小世界=一拍砸穿半个世界，踩过的坑）；调零=太空漂移；给不同物体不同系数=气球升空、羽毛缓降。
- 业内标准：全局一个重力值，每个物体挂一个"缩放系数"（gravity scale：浮空怪 0.5、气球负值）——而不是逐物体各写一个重力。Box2D/Unity 都是这么做的。
- 咱们：✅ 常量已有并按世界尺度定标（1-2 格/拍²）；"免重力集合"就是系数 0 的等价物，将来要细化改成逐实体系数。

#### 阻力 / 阻尼 linear damping ✅
- 白话：空气（或水）的拖拽——飞出去的东西慢慢减速，不是永远匀速。
- 管什么：弹道的形状（拖尾弧线还是平直炮线）、滑行的东西多久停下。
- 动它会怎样：零阻力=炮弹永远飞直到撞墙；阻力太大=什么都软趴趴飞不远。
- 业内标准：damping 参数，每拍速度×(1-阻尼值) 衰减；两种数学模型——线性（游戏主流，稳定）和平方（真实弹道用）；战地是每把枪单独调一组重力阻力参数。
- 咱们：✅ 已做到战地级形态：定律统一（一切飞行物都受）+每颗弹丸自带参数组（#033）。

#### 浮力 buoyancy ⬜
- 白话：水把浸进去的东西往上托的力——船能浮、石头沉，都是它跟重力的拔河。
- 管什么：东西落水是沉是浮；游泳、船、水下世界的地基。
- 动它会怎样：没有它，水面跟空气没区别——铁块和木头落水一样直沉到底。
- 业内标准：Box2D/Rapier 都不内置，全行业都自己写——传感器测浸水体积+阿基米德公式+补一点阻尼防上下弹跳。
- 咱们：⬜ 液体/游泳玩法出现再做，落地路线已写死（上面那套标准做法）。

#### 力 / 冲量 / 力矩 force / impulse / torque ⬜
- 白话：三种"推"——力=持续推（火箭喷气）、冲量=猛推一下（击退、起跳）、力矩=拧（让它转起来）。
- 管什么：一切"东西被改变运动状态"的标准接口，力系统的总开关。
- 动它会怎样：没有这套接口，击退、爆炸推人、跳跃每个都得各写一个特例。
- 业内标准：三大引擎的标准三接口。
- 咱们：⬜ 等击退/动量类玩法出现（和碰撞响应同期立）。

#### 力场 force field 💎
- 白话：一片区域里持续的力——风区、水流域、磁吸区、黑洞。
- 管什么：让"地形"不只是墙，还是能推人的地形：走进风区被吹走、靠近磁铁被吸走。
- 动它会怎样：有了它，防守方可以给自己周围"改空气"（加大阻力=飞来的弹丸被拖慢提前坠落=物理护盾）——这是咱们独有的攻防对等玩法，六家都没有。
- 业内标准：体积传感器+每帧施力（虚幻 Chaos 场等）。
- 咱们：💎 咱们的版本更狠——场可以被玩家调制（#029），等场玩法立法。

### 1.3 碰撞（Collision）——东西怎么"遇到"东西

#### 离散碰撞检测 discrete ✅
- 白话：每拍结束时看一眼"谁跟谁叠上了"，叠了就算撞。
- 管什么：最基础、最便宜的撞车判定。
- 动它会怎样：高速的东西会"穿墙"——一拍位移大于墙的厚度，就从中间过去了（隧穿）。
- 业内标准：所有引擎的默认模式。
- 咱们：✅ 基础层（活动圆 vs 静态方块，钳制点判定）。

#### 连续碰撞检测 CCD（Continuous Collision Detection）✅
- 白话：不看点，看"这一拍走过的整条线"——线上扫到谁就是撞了谁。子弹不会从人中间穿过去。
- 管什么：高速物体（弹丸）的撞人判定，隧穿的根治手段。
- 动它会怎样：没有它，越快的弹越打不中人（漏结算），"速度"就成了bug。
- 业内标准：Box2D 给高速物打 bullet 标记、Rapier 用预测距离。
- 咱们：✅ 已落地（#034：整条线段扫掠+多目标取最近的）。

#### 宽相 / 窄相 broad phase / narrow phase ⬜
- 白话：两层漏斗——先粗粗圈出"哪几对可能撞"（宽相），再对这几对精算（窄相）。
- 管什么：性能。几百个实体互相检查时，不筛选就是上千次废话计算。
- 动它会怎样：东西少时无所谓；东西上百后没有它世界直接卡死。
- 业内标准：一切引擎的标准结构（AABB 树粗筛）。
- 咱们：⬜ 实体数上百再上。

#### 碰撞响应 collision response ⬜
- 白话：撞上之后弹不弹、蹭不蹭——两个数管两件事：弹性（1=台球一样弹，0=沙袋一样停）和摩擦（冰面滑vs草地涩）。
- 管什么：碰撞的"手感"——撞击是干脆的、Q弹的、还是一撞就死的。
- 动它会怎样：没有它，撞上就是急停（咱们现状）；有了它，炮弹打飞石块、冰面打滑全涌现。
- 业内标准：弹性系数+摩擦系数，冲量求解器迭代算（Box2D/Rapier 标准）。
- 咱们：定案"撞=停不推"，等击退/动量玩法出现再立。

#### 触发器 trigger / sensor ✅
- 白话：隐形地毯——踩上去/离开时报个信，但本身不产生物理推挤。
- 管什么：地雷、区域警报、进出警戒区，一切"进入某片区域就如何"的标准实现。
- 动它会怎样：没有它，每个区域事件都得硬写坐标判断。
- 业内标准：引擎标准件。
- 咱们：✅ 接触通道（相触+边沿触发：贴着只报一次，不刷屏）。

#### 碰撞分组 collision groups / layers 🟡
- 白话："什么能撞什么"的配置表——子弹穿过队友、撞不到墙的幽灵，都靠分组掩码表达。
- 管什么：例外规则的数据化——不写 if，填表。
- 动它会怎样：没有它，每种"谁不撞谁"都要写死在代码里，越积越乱。
- 业内标准：引擎标准件（层掩码）。
- 咱们：弹丸豁免已用声明式条款实现（binding），掩码形式等实体类型多了再上。

#### 查询 raycast / shapecast / overlap ✅
- 白话：向世界问三个问题——"这条射线上有什么？""这个形状压到了谁？""这个圈里有谁？"
- 管什么：视线、瞄准、探测——"看见什么"的地基。
- 动它会怎样：没有它，玩家代码只能靠猜（盲人摸象）。
- 业内标准：引擎标准三接口。
- 咱们：✅ scan/probe（probe 还带元数据：命中能返回发射者身份）。

### 1.4 约束与特殊体（Joints & Special Bodies）——把东西"连"起来

#### 关节 joints ⬜
- 白话：把两个物体拴在一起的标准方式——绳（拴住距离）、门轴（铰链）、滑轨（电梯）、弹簧（拉得越远回弹越猛）。
- 管什么："连着的两个东西"怎么互相牵制——塔吊、锁链、拖车全靠它。
- 动它会怎样：没有它，连体物只能焊死成一个整体，软连接玩法（链条桥）做不了。
- 业内标准：Box2D/Rapier 自带 8~10 种标准关节。
- 咱们：⬜ 绳索/连接体玩法出现再做（到时是抄标准件）。

#### 软体 / 布料 soft body / cloth ⬜
- 白话：用一堆质点+弹簧搭出来的"软东西"——旗子飘、肉虫蠕动。
- 管什么：柔性形态的表现与物理。
- 动它会怎样：没有它，万物都是刚体铁疙瘩。
- 业内标准：质点-弹簧模型（verlet 积分）；大作用 Chaos/PhysX。
- 咱们：⬜ 可能远期（生物学形态玩法）。

#### 布娃娃 ragdoll 🚫
- 白话：死亡瞬间把身体交给物理乱甩——经典的"死人布娃娃"。
- 管什么：死亡的表现力（动作游戏标配）。
- 业内标准：死亡时从动画切换到骨骼物理。
- 咱们：🚫 死亡=结算事件不是物理表演；前端已有渐隐✕当死亡反馈。

#### 载具 vehicle ⬜
- 白话：车的一套标准物理模型——轮子用射线悬挂+侧向摩擦，不是真的算四个轮子。
- 管什么：开起来像车的车。
- 业内标准：各引擎都有 vehicle 模板。
- 咱们：⬜ 载具玩法（连接体之后）。

### 1.5 流体（Fluids）——水怎么做

#### 真流体（粒子/网格模拟）🚫
- 白话：每一滴水都真算的流体。
- 管什么：画面级真实的水。
- 动它会怎样：极贵——大作也只拿来渲染不拿来玩。
- 咱们：🚫 不做。

#### 拍制流体（体积守恒+液位平衡）💎
- 白话：Factorio 的简化水——连通的管道全体自动找平，不逐格算。
- 管什么：确定性又便宜的液体，专为拍制世界设计。
- 动它会怎样：液体玩法（河流/水压/灌溉）全靠这套模型起步。
- 业内标准：Factorio 液位模型（连通段等液位求平衡）；MC 用规则蔓延。
- 咱们：💎 液体玩法出现时整套抄 Factorio（与咱们物理哲学同构）。

### 1.6 时间步与确定性（Timestep & Determinism）——物理的"心跳"

#### 固定步长 fixed timestep ✅
- 白话：物理按固定节拍算（像秒针嗒嗒走），不跟着画面帧率跑。
- 管什么：确定性的地基——节拍固定，同样的操作才有同样的结果。
- 动它会怎样：跟着帧率跑=快机器世界快慢机器世界慢，回放和同步全崩。
- 业内标准：引擎标配；MC 20拍/秒、Factorio 60拍/秒。
- 咱们：✅ 1秒/拍；提速到 5~10 拍/秒已定方向（三件配套齐动）。

#### 子步 substeps ✅
- 白话：一拍里再切几小步算，粗活细干。
- 管什么：精度——拍大动作快时一拍算一次不够准。
- 业内标准：Rapier CCD 子步（有下限防数值不稳）。
- 咱们：✅ 弹道预览按弧长细分采样就是同思想。

#### 确定性 determinism ✅
- 白话：同版本+同种子+同操作=逐拍一模一样的结果——像录像带重放。
- 管什么：比赛公平、回放、仲裁"谁先动的手"，全靠它。
- 动它会怎样：随机数一进来（或浮点运算换机器），两边世界就分叉，没法对账。
- 业内标准：Factorio 做到极致（可全程回放）；坑在跨平台浮点差异。
- 咱们：✅ 已消随机（EntityId 定序）；replay ⬜ 等比赛/仲裁需求。

#### 速度上限 speed cap ✅
- 白话：万物极速封顶——再快的弹也不许超。
- 管什么：两个身份要分清——工程护栏（防数值爆炸）和玩法立法（保画面可读，telegraphing）。
- 动它会怎样：不封顶=光速怪出现，谁也看不见谁，弹道没法看。
- 业内标准：引擎有 max velocity 参数（工程身份）。
- 咱们：✅ 世界极速=视觉可读性常数 25 格/拍（#034，立法身份已辨析清楚）。


## 第 2 章 战斗结算系统（Combat Resolution）
