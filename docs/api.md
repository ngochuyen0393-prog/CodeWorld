# CodeWorld 玩家接口宪法 v1.1

> 面向读者：会写代码的玩家。你写的 WAT 模块就是你在世界里的身体。
> 宪法：能力归框架，玩法归玩家。框架只提供下面的原语，怎么活是你的事。
> 设计依据：`docs/world-foundation.md`（一个基座两扇门三张合同）+ `docs/architecture.md`。

## 一、实体导出函数契约

你的 WASM 模块可以导出以下函数，框架按节奏调用：

| 导出 | 签名 | 必需 | 调用时机 |
|---|---|---|---|
| `life` | `() -> i32` | **必需** | 每拍一次 |
| `on_tick` | `() -> ()` | 可缺省 | 每拍一次（life 之前） |
| `on_probe` | `(i32) -> i32` | 可缺省 | 被其他实体 probe 时 |
| `on_attack` | `(i32) -> i32` | 可缺省 | 被攻击收件时（每刀一次） |
| `on_contact` | `(f64, f64) -> ()` | 可缺省 | 新进入物理接触时（双方各一次，边沿触发） |
| `on_death` | `() -> ()` | 可缺省 | 死亡清理前（遗嘱窗口，世界托管执行） |
| `on_field` | `(i32, i32, i32) -> i32` | 可缺省 | 声明了力场（field_radius>0）且已成型时，世界每拍询问一次 |
| `on_command` | `(i32, i32) -> ()` | 可缺省 | 母体 command 广播到达时（下一拍 a-1 投递） |
| `on_report` | `(i64, i32, i32) -> ()` | 可缺省 | 活链孩子 report 到达时（from=发送造物 id 低 64 位） |
| `on_message` | `(i64, i32, i32) -> ()` | 可缺省 | 其他实体 send 到达时（from=发送方 id 低 64 位） |

- **`life()` 返回 1 = 继续存在；返回 0 = 主动自尽。** 缺 `life` 导出或调用失败，第一拍就会被框架判定死亡——没有 `life` 的模块活不过一拍。
- `on_tick` 是你的主逻辑入口（找敌人、移动、出刀都在这里）。
- `on_attack` 参数是攻击 payload 的前 4 字节（LE 转 i32）；返回非 0 = 拦截这一刀。每次调用消耗你的 fuel（围殴 = 磨你的算力）。不导出 = 不设防。
- `on_probe` 参数是探测 request 的前 4 字节；返回值作为 response 前 4 字节透传给探测方（框架只搬运不审查——撒谎是你的自由，但体徵藏不住，见 `probe`）。
- `on_contact` 参数是**对方坐标** `(other_x: f64, other_y: f64)`（坐标寻址，不传 EntityId，与 scan/probe 同哲学）。新进入接触的对，双方各收一次（持续贴着不重复，分开再碰再触发）；世界零过滤——白名单/敌我判断是你自己的代码写的。每次调用消耗一小笔独立 fuel 预算（不占你的 tick 配额，见下）。
- `on_death` 是**遗嘱钩子**：死亡清理前世界托管执行一次（#043 死亡谢幕——生前签好条款世界照办，本人无需在场）。限步数 = 预算即上限，烧尽即遗嘱写不完，世界不补偿不重试。不导出 = 无遗嘱（现状行为）。

最小可玩模块（仓库模板 `players/_template.wat.txt`，复制改名 `<你的名字>.wat` 即进场）：

```wat
(module
  (import "env" "log" (func $log (param i32)))
  (func (export "life") (result i32) i32.const 1)
  (func (export "on_tick") i32.const 1 call $log))
```

### `on_contact(other_x: f64, other_y: f64) -> ()`

接触回调（D-007，与 `on_attack`/`on_probe` 同族第三兄弟）：某实体**新进入**物理接触时，框架通知双方的代码各一次——你收到的参数是**对方**的实况坐标。地雷（被踩才响）、区域警报（有东西进圈）、哨戒圈（靠近就警戒）三类玩法从这一个原语长出。

- **时机**：物理步后的边沿触发——只对"上一拍没贴、这一拍贴上"的对触发；持续贴着不重复（防刷屏），分开后再碰再触发。弹丸不参与接触通道。
- **燃料**：host 侧独立小预算包裹（默认 10_000 指令，`CODEWORLD_CONTACT_FUEL` 可调；架构 3.3 `contact_target_instruction_limit` 与 probe 同档）——恶意死循环最多烧预算值，不占你的 tick 配额，也不污染你的 fuel 记账。
- **不导出**：no-op，零开销（与不导出 `on_attack` = 不设防同款防御）。
- 通知里排队的攻击走既有管线（下一拍 collect，不插队）；**世界零过滤**——双方都收通知，白名单/敌我/可信判断是你自己的代码写的（probe 应答博弈同哲学）。
- **限流互斥**（收尾补充）：`on_contact` 里排队的 spawn 滞留到**下一拍**阶段二统一放行（a1 drain，排在当拍 drain 之后）——下一拍你自己的新 spawn 请求会撞上"每拍一个"限流被拒（返回 0）一拍，再下一拍恢复。想把接触回调当实时扳机用，给自己的发射/造物节奏留一拍余量。

### `on_death() -> ()`

遗嘱钩子（D-007，#043 身份体系的"骨架出厂槽位"最小落地）：死亡谢幕——你生前在 `on_death` 里排队的 spawn（【D-018】shoot 通道已退役——烟花=遗嘱 spawn 造物带出生初速），死亡触发时世界**托管执行**（遗嘱模式：生前签好条款世界照办，本人无需在场），跑完销毁。猝死也有体面。

- **时机**：死亡清理步之前（沙箱还在），对本拍死亡的实体逐个执行；decay/被杀/`life()`=false/处置期死亡全触发。**残影消散不触发**（消散≠死亡谢幕）；**登出带走（take）不触发**（会话级离场非死亡）。
- **限步数 = 预算即上限**：独立 fuel 预算（默认 200_000 指令，`CODEWORLD_DEATH_FUEL` 可调；架构 3.3 `death_instruction_limit` 数值与 attack_target_instruction_limit 同档位 200_000——on_attack 本身无独立预算，跑在攻击目标剩余 tick fuel 上，此处仅数值对齐）。燃料耗尽遗嘱写不完——世界不补偿不重试（遗嘱有字数上限，诚实的代价）。
- **遗产归属**：遗嘱里排队的 spawn（遗物/烟花——【D-018】烟花=spawn 造物带出生初速）**当拍生效**，产权链照常继承（创造者已死不拒绝——遗嘱执行人资格）；排队的 attack **丢弃**（死人不出刀）。
- **不导出**：无遗嘱，死亡路径与从前完全一致（零回归）。

### `on_field(n_ptr: i32, ids_cap: i32, ids_ptr: i32) -> i32`

力场询问应答（D-012 协议 v3，host→沙箱调用）：你声明了力场（spawn 第 15 参 `field_radius`>0）且过了成型期，世界**每拍问一次**"你的场现在多强"。这是场的表达权通道——但世界有结算权（域钳制+代数和最终裁定）。

- **通信契约**：调用前世界把域内实体数 `n`（i32 LE）写进 `n_ptr` 处、实体清单写进 `[ids_ptr, ids_ptr+8×min(n, ids_cap))`（每个实体 = EntityId 低 64 位，8 字节小端；含非玩家实体，**不含场源自己**；EntityId 升序确定序）。**只报"谁在"不报"谁是谁"**——身份判断归你的代码（零预设：敌我识别、白名单都是你写的）。
- **场信箱 = 你的线性内存末尾 516 字节（4 字节 n + 64 槽×8 字节清单），世界保留，请勿占用**——地址跟你的 memory 声明走（你声明多大信箱就在多高处）；内存不足 516 字节时世界放弃询问，按出生声明结算。
- **返回值**：`0` = 维持出生声明（笨场，几步完事）；`k≠0` = 本拍阻力改写量临时改为 `k`（智能场：按 ids 清单烧识别步数后返回差异化数值）。应答只影响**本拍**，下一拍重新问。**粒度注意**：`k` 是 i32 整数——小数级改写（如 +1.95）只能靠出生声明（spawn 第 17 参），应答通道只做整数级临时调整。
- **截断注意**：清单最多 64 条（信箱容量）。域内实体数超 64（世界实体上限可经 `CODEWORLD_MAX_ENTITIES` 调大）时清单截断为前 64 条，世界日志有 warn——你读到的 `n=64` 既可能是"恰好 64"也可能是"被截断"，需要精确计数时自行 probe 辅助。
- **燃料**：独立小预算包裹（默认 10_000 指令，`CODEWORLD_FIELD_FUEL` 可调）——询问不占你的 tick 配额；预算内 world 写信箱的通信成本也不扣你的账。
- **失败诚实**：on_field 抛错/签名不匹配/未导出 → 本拍按出生声明结算（世界不用坏数据）。操控接管/处置等待**不豁免**询问（场是出生声明的每拍核实，与 life 同级的存在合同）。
- **窗口注意**：on_field 执行窗口内 probe 不可用（probe 桥只挂 on_tick 窗口）；get_pos/scan/visible 照常。

## 二、已开放 import（20 个）

所有 import 挂在 `"env"` 命名空间下（决斗窗口内另有 `duel_read`/`duel_write`/`duel_round` 三个游魂专属 import，见「五点一」）。玩家代码读到的世界状态是**本拍开始时的快照**（你动、别人也动，实际结果下一拍才感知）。

### `log(v: i32)`

日志。`v` 是你自定义的 marker，原样进运行日志（`[player_log]` 行）。无返回。

### `get_pos() -> (f64, f64)`

读自己的坐标 `(x, y)`（本拍快照）。

```wat
(import "env" "get_pos" (func $get_pos (result f64 f64)))
;; 调用：多值返回先压 x 再压 y
(call $get_pos)  ;; 栈顶: y, x
```

### `scan(x_ptr: i32, y_ptr: i32) -> i32`

锁定最近的敌人（**仅视野内**：viewport 屏幕范围内的存活实体，架构 4.2 攻击前置条件"视距内"；默认视口以 (0,0) 为中心、半宽 50 半高 25——"屏幕"就是前端画面的世界坐标投影）：把敌人坐标写进你的 memory（x 8 字节 @`x_ptr`，y 8 字节 @`y_ptr`）。返回 `1` = 找到；`0` = 视野内没有其他存活实体，或写入指针非法（此时不写 memory）。液体造物照常可被 scan 探到（布景与规则分层）。

视野外（屏幕外）的实体 scan 锁不到——框架不提供任何超视距坐标能力（decisions.md #018）；超视距手段自己构建：自建哨兵网络（造物视野拼接）、规则逆向/运动建模推理盲打。

```wat
(import "env" "scan" (func $scan (param i32 i32) (result i32)))
;; scan(0, 8) 后 f64.load(0)=敌人x、f64.load(8)=敌人y
```

### `move_by(dx: f64, dy: f64) -> i32`

相对移动：目标点 = 当前坐标 + 偏移，排队后由框架在本拍阶段二应用。返回 `1` = 已排队；`0` = 拒绝。

拒绝条件：`dx`/`dy` 非有限（NaN/无穷）；目标点非有限；目标 `y < ground(x)`（钻地——D-016 起地面是高度数组，平地世界退化为 `y < 0`）。

**身体不重叠（decisions.md #030 半径碰撞，取代已退役的 #021 一格一物）：** 排队成功 ≠ 移动成功——阶段二统一裁决：目标位置与任何存活实体身体（圆/方块）重叠 → **分轴滑动**（先试整步，撞则试 `(new_x, old_y)`，再试 `(old_x, new_y)`，都撞则原地不动——贴墙滑而非整步作废）。被挡记 INFO 日志"移动被挡（身体重叠），分轴滑动裁决"（含占据者）。同拍多个移动按实体 id 升序统一裁决（先到先得，确定序）。落地钳制：`y < 自身半径` 时钳到半径线（脚贴地，圆心即位置）。被挡不算错误，下一拍重试即可。

注意：同一拍内多次调用各自从同一快照计算绝对目标，只有最后一次生效——**每拍只 move 一次**。

### `hover()`

悬停声明（期四第七刀）：宣告"**本拍**我要悬停"。无参无返回，只置位——世界在阶段一收件后把你并入当拍**免重力集合**（与操控飞行同集合同机制，decisions.md #030 升力独立），本拍物理步不给你扣重力。被挡、滑动、被出刀都不影响升力（被挡 ≠ 坠落）。

- **每拍重申**：声明不跨拍延续——上一拍 hover 过不代表这一拍还悬停着。要持续悬停就得每拍调用（"持续对抗世界规则"的代码体现，#029 无税但需持续出力）。漏调的那拍重力照扣，直接开坠。
- 悬停不给你位移：想动还是走 `move_by`（悬停 + 移动可同拍并用）。
- 典型用法：高台哨兵/间谍每拍 `call $hover` 站稳空中坐标——坐标稳定换来的是"被点名必中"（#031 点命中制），暴露就是悬停的真实代价。

```wat
(import "env" "hover" (func $hover))
;; on_tick 里每拍先声明悬停，再跑自己的逻辑：
(call $hover)
```

### `thrust(dx: f64, dy: f64) -> i32`

给自个儿一记冲量（dev-plan.md D-010 冲量小刀，第 14 个 import，2026-10-21 落地）：本拍给自己加速度，速度字段叠加后由本拍物理步的速度积分路径带位移——**跳跃/踏水推进/轻功水上漂的地基**（D-010 自主出力）。返回 `1` = 已排队；`0` = 拒绝（NaN/无穷输入、剩余 fuel 不足本次出力）。

- **力出自己身**（铁律）：冲量只作用于自己，不开放"推别人"API——推人走碰撞（撞=动量交换，D-010）或击退 payload（`attack_at` 第 5 参 `force`，力度=攻击者声明的攻击伴生件），与"攻击形态归玩家"同哲学。
- **#021 切割声明**：已退役的"推挤"（持续重叠互相挤开→连体 bug）≠ 冲量（一次性动量交换，撞完就分）——thrust 是一次性冲量非持续推挤。
- **调用时机**：本拍排队（阶段二统一应用），同拍物理步即吃重力积分位移——`v += impulse` 后走"重力入速度→阻力→世界极速钳→位移→落地解析"。落地（贴地面/身体）= **法向清零+切向×(1-f)**（D-010 摩擦语义：默认 f=0.6 水平分量×0.4 逐拍衰减，数拍内自停；贴地滑行白拿位移仍不合法——CCD 起步即在地面口径当拍截断，想平移走 `move_by`）；空中不清，重力逐拍累积。
- **单次上限 7.7 格/拍**：向量模长超限归一化压回（方向不变）。推导（1.7 标定法）：跳跃 ≤3 格高锚点 → v0 = √(2·9.8·3) ≈ 7.67，取 7.7。**满力一次 = 跳 3 格高**。
- **fuel 代价**：`cost = (有效模长/7.7) × (fuel_limit × 5%)`——满力一次 ≈5% fuel。fuel 每拍重发，本拍出力吃本拍预算（同拍挨刀的 on_attack 防守用的是扣完的剩余量）。**static 钉死造物出力无效**（钉死就是钉死，fuel 照扣=诚实的代价，同 D-009 "岸上空烧 fuel 踩水"哲学）。
- **弹道手感**：地面 `thrust(0, 7.7)` 起跳→升空约 2.85 格→次拍弧线回落落地，全程非瞬移（逐拍位移 ≤ 世界极速 25）。水平冲量贴地打不出位移（起步即在地面口径当拍截断，速度×(1-f) 衰减不出位移）——thrust 管跳跃与腾空机动，走路归 `move_by`。

```wat
(import "env" "thrust" (func $thrust (param f64 f64) (result i32)))
;; 满力起跳（0, 7.7）——每 4 拍跳一次的节奏见 players/jumper.wat：
(f64.const 0.0) (f64.const 7.7) (call $thrust) (drop)
```

### `attack_at(x: f64, y: f64, payload_ptr: i32, payload_len: i32, force: f64) -> i32`

对坐标 `(x, y)` 出刀，payload 从你的 memory `[ptr, ptr+len)` 读取（D-005 决斗制落地后：**非空 payload = 你派出的游魂**，命中后登陆对方沙箱开战——不再是"换对方代码"）。返回 `1` = 已排队；`0` = 拒绝（`payload_len` 超过 1MB 上限，或 `force` 非有限——整刀作废）。

- 空 payload（ptr/len 为 0 或模块没导出 memory）= **默认击杀刀（裸奔特例）**：守方无防御即零时长瞬间拿下（life 变 0），行为与旧"换血"完全等价。
- 非空 payload = **游魂刀**：命中（未被拦截）后世界为你们俩开一条决斗会话，你的游魂每拍拿一个窗口在守方内存里读写（原语见「五点一、决斗制（D-005 刀0）」节），**不再直接换血**。
- 对方的 `on_attack` 拦截判定保留：拦截成功 = 刀被挡在门外，**不开会话**（payload 白带，你的游魂死在门口）。
- 攻击打的是**点**不是编号（decisions.md #031 点命中制）：点落在实体身体内即命中——圆=距圆心 < 半径严格、造物=格对齐 AABB 内；半径内多个命中取最近者（同距按 EntityId 升序）。站桩目标必中；对方在移动（出刀拍位移超半径）就打空——猫鼠博弈在走位本身。
- **贴身刀**（decisions.md #034，弹道系统落地）：点找得到目标还要**够得着**——你与目标的距离 < 你的半径 + 目标半径 + 0.5（0.5 是"接触容差"物理判距常量，不是射程属性——射程不立法，全部物理涌现）。够不着 = 落空（日志原因"距离不足"，与"点不在任何身体内"区分）。想打远处？那是你自己拼投掷器的事（spawn 一体式造物弹，见 docs/newbie-first-thrower.md）。
- **击退力度 `force`**（D-010 第 5 参，格/拍的速度增量单位）：**力度=攻击者声明**（宪法 #011——世界不替你定力度）。命中时目标沿攻击来向吃一记速度增量 `v += force·方向`（过世界极速 25 钳制）——**传 0 = 不击退**（零回归）。校验：非有限（NaN/无穷）= 整刀作废拒绝；负值钳 0；上限钳世界极速 25（恰等放行）。**拍的边界**：击退写的是速度字段，位置下一拍物理步才动——当拍距离门照常按位置复核，位移下一拍兑现（击飞的真实时序，无瞬移）。击退不中断决斗（会话跟身体走）。
- 实际拦截/会话开设/击杀在框架两阶段结算中完成（下一拍才能感知战果）。

### `probe(tx: f64, ty: f64, req_ptr: i32, req_len: i32, resp_ptr: i32, resp_cap: i32) -> i32`

探测可见实体（坐标寻址，只读，不扣你的手续费）。request 字节从你的 memory 读取；对方的 `on_probe` 返回 + **24 字节被动体徵尾块**写入你的 memory `[resp_ptr, ...)`。

返回值：
- `>= 0`：实际写入字节数（response + 24，超过 `resp_cap` 截断）
- `-1`：坐标无可见实体 / 响应不可写
- `-2`：目标没有 `on_probe` 导出（响应位置已写默认被动体徵）

（历史注记：`-3` 发射痕迹返回值随 #045 弹丸退役一并退役——造物弹天然在 visible 列表暴露，独立痕迹机制已移除；老文档提到 probe 命中痕迹坐标拿发射者身份的玩法，造物弹时代=对弹本身 probe。）

被动体徵尾块 24 字节（u64 LE × 3，host 采集、玩家代码伪造不了）：

| 偏移 | 含义 |
|---|---|
| `[0..8]` | 目标 api_calls 计数（它调了多少次 import） |
| `[8..16]` | 目标 fuel 剩余（探测前快照） |
| `[16..24]` | 本次 `on_probe` 消耗的 fuel |

比对对方的话（response）和它的体徵（尾块），是识破伪装的路子。目标 `on_probe` 跑在独立小 fuel 预算上，恶意死循环烧不动你的 tick。

### `spawn(code_ptr: i32, code_len: i32, x: f64, y: f64, glyph_ptr: i32, color_ptr: i32, radius: f64, mass: f64, binding: i32, motion: i32, vx: f64, vy: f64, blob_ptr: i32, blob_len: i32, field_radius: f64, field_gravity_scale: f64, field_drag_delta: f64, liquid_density: f64, liquid_drag: f64, link: i32, restitution: f64, friction: f64, lifespan_ticks: i32) -> i32`

造物（门二）：提交一段 WAT 源码 + 出生坐标 + 外观 + 身体/质量参数 + **绑定契约** + **运动身份** + **出生初速** + **出生数据包**，请求造一个新实体。**造物是活实体，不是装饰**——从下一拍开始跑自己的代码，生死由它自己的 `life()` 决定（自治锚合同，存续与你的在线状态无关——除非你声明了契约）。

参数都从你的 memory 读：

| 参数 | 含义 |
|---|---|
| `[code_ptr, code_len)` | 造物 WAT 源码（UTF-8 文本，≤ 1MB） |
| `(x, y)` | 出生坐标（绝对坐标） |
| `[glyph_ptr, ...)` | 字形：NUL 结尾字符串，**恰好 1 个字符** |
| `[color_ptr, ...)` | 颜色：NUL 结尾字符串，非空 |
| `radius` | 身体半径（#030 第 7 参；合法域 0.05..=25.0，超界警告并钳制，非有限值回退 0.5。static 造物身体=占地格 AABB 不用它；**dynamic 造物（motion=1）身体=此半径的圆**） |
| `mass` | 质量（#034 第 8 参；合法域 0.05..=100.0，超界警告并钳制，非有限值回退 1.0。物理人格属性：只参与物理反应——将来击退/动量碰撞的受力分母——**永不参与攻击结算**） |
| `binding` | **绑定契约**（#034 修订四第 9 参，出生声明写进造物数据、世界每拍托管执行）：`0`=unbound（默认，同生不共死——你死塔照站，现状）；`1`=fade_on_death（同生共死——你死的那一拍塔即刻消亡，INFO 日志"同生契约生效，随主消亡"）；`2`=grace_owner（你的造物出刀永不伤 bound_to 主人——命中主人=哑弹；不声明则误伤合法：**世界不豁免，豁免是声明**，#035 修订四原文）。非法值警告并按 0 处理 |
| `motion` | **运动身份**（D-003 第 10 参，decisions #048）：`0`=static（默认，钉死——身体=出生格 1×1 AABB，不吃速度物理，现状）；`1`=dynamic（**全活**——身体=声明 `radius` 的圆，出生拍起受完整物理：重力落点解析/速度矢量阻力衰减/世界极速钳制/移动裁决/接触通道，与生物同管线；"被撞飞"等碰撞响应是 D-010 的事）。非法值警告并按 0 处理。kinematic（剧本档）暂未开放 |
| `vx`, `vy` | **出生初速**（第 11/12 参，D-018）：造物出生即带的速度矢量——出生动量=物理事实非攻击预设。有限且模长 ≤ 世界极速 25（严格 `>` 拒绝，恰等放行）。static 造物钉死不吃速度物理，初速仅对 dynamic 造物有物理意义（照存不裁） |
| `[blob_ptr, blob_len)` | **出生数据包**（第 13/14 参，≤ 64KB）：世界不解释内容，母体传讯/代际遗传通道（类似 Screeps `opts.memory`）。超限**整次拒绝不裁剪**（裁剪=偷改玩家数据）；造物代码用 `birth_blob` 读回 |
| `field_radius` | **场域半径**（D-012 第 15 参，力场出生声明家族）：以造物身体中心为锚向外延伸的参数改写区半径。域 [0.0, 25.0]，0=无场（默认=现状）；非有限/负值警告并钳 0（无场），超上限钳 25.0。详见「力场（D-012）」节 |
| `field_gravity_scale` | **场重力缩放**（D-012 第 16 参）：生效重力 = 世界重力 × scale。域 [0.0, 10.0]，1.0=不变（默认）；非有限值警告并钳 1.0，负值钳 0（零重力域），超上限钳 10.0 |
| `field_drag_delta` | **场阻力改写量**（D-012 第 17 参，**加法式**不是缩放）：生效阻力 = 世界阻力 + delta。域 [-1.0, +25.0]，0=不改写（默认）；非有限值警告并钳 0，超域钳边界。正负互吃（叠加 v2 代数抵消），详见「力场（D-012）」节 |
| `liquid_density` | **液体密度 ρ**（D-009 第 18 参，液体出生声明家族）：域 [0.0, 5.0]，0=非液体（默认=普通造物零回归）；>0 即声明"我的身体区域（格对齐 AABB）是水域"。参照系=水 1.0 无量纲，世界只认数字不认名字（"油 0.75/蜂蜜 1.4/岩浆 2.5"是社区预设非内置清单）。非有限/负值警告并钳 0，超上限钳 5.0。详见「液体（D-009）」节 |
| `liquid_drag` | **水中阻尼 k**（D-009 第 19 参）：每拍速度保留系数的 MC 语义——水中一步 `v ← v×k_eff + 浮力改写重力`，`k_eff = clamp(k, 0, 1)`（声明域 [0,5] 宽松、结算域 [0,1] 收紧，不许凭空加速）。域 [0.0, 5.0]，0=无阻尼声明合法；非有限/负值警告并钳 0，超上限钳 5.0。k=0.35 → 入水一拍速度掉 65% |
| `link` | **链声明**（D-011 第 20 参，binding 家族新成员——契约管生死、链管通信，两轴正交自由组合）：`0`=无链（默认=放生，现状零回归）；`1`=活链（母体 `command` 下行广播可达、自己 `report` 沿链上行）。非法值警告并按 0 处理。断链唯一事件=母体实体死（当拍 link_to 清 None，INFO 一条汇总）；断链不杀造物——电话挂了人活着。**夺剑注意**：链是实体字段，造物被决斗攻陷后链仍连原母体——新主照收原母体的剑诀广播、可用 report 伪装上行（"放风筝的人自己也在被钓"，#038 原文零新立法）。详见「世界内链路段（D-011）」节 |
| `restitution` | **弹性 e**（D-010 第 21 参，碰撞响应出生声明家族——与 radius/mass/liquid 同门，世界只认数字不认名字：钢珠/黏土/橡胶是玩家黑话）：域 [0.0, 1.0] 硬钳，非有限值警告并回退 0.0。0=撞停（默认=撞停流派零回归），1=完全弹性。**高弹注意**：1 拍/秒的拍制世界里高弹=肉眼分格跳动，0.5~0.6 是手感甜点（火箭联盟球 0.6 调研定论）。接触对组合=取大 `max(e1, e2)`（"弹力球不需要弹力地板"——高弹实体撞地面照样弹）；相对法向速度 < 1 格/拍按非弹性处理（低速闸防抖）；每对每拍最多结算一次反弹 |
| `friction` | **摩擦 f**（D-010 第 22 参）：域 [0.0, 1.0] 硬钳，非有限值警告并回退 0.6（Box2D v3 新默认"比冰滑比橡胶涩"）。切向速度每拍撞触后 `×(1-f)`——0=冰面（滑行不衰减）、0.6=草地（数拍内停）、1=瞬停。接触对组合=几何平均 `√(f1×f2)`（一方冰=接触即冰）。落地下拍滑行、贴坡速度非零的实体会沿坡缓降（球在坡上会滚下来——物理涌现）；想停在坡上就把速度磨到 0（静=静零回归） |
| `lifespan_ticks` | **造物寿命**（D-019 第 23 参，出生声明家族，**R1 起强制声明**）：域 [1,+] 无上限（WAT 侧 i32，无非有限值）。**强制声明**：0（=不声明）与负值同罪，**整次拒绝出生**（返回 0；#030 整次拒绝哲学——机关枪满地永生子弹的口子焊死）。>=1=声明活 N 拍，到拍世界托管消散——到期判定 `current_tick >= 出生拍 + N`（出生拍算第 0 拍，活满 N 拍第 N+1 拍消散）。到期消散=**自然消散**：非击杀无掠夺（survival 点数谁都不动）、**遗嘱不触发**（on_death 不执行，与残影消散同判）；与代码自管死法（life()=false / fade_on_death 契约死）正交，谁先到谁触发。液体造物（布景）带寿命同样到期消散（临时水域合法）——世界只认声明不认身份。返回值：1=已排队，0=被拒（当场知道）。**建议值（按拍速挂钩秒数，拍速升级手册同步换算）**：法术/子弹类"活三五秒就行"——当前 1拍/秒 ≈ **3~5 拍**（打不中的弹几秒后自己收场不堵门；拍速升 5~10拍/秒后同款秒数换算成 15~50 拍）；建筑/塔/景观类长期存在——按"年"自算：1拍/秒 ≈ **3150 万拍/年**（想要一座活两年的塔 ≈ 6300 万拍，声明多少活多少，无上限）。**直觉口径：寿命跟秒数挂钩，不背裸拍数**。出厂模板弹 30 拍=模板里明写的声明值，看得见改得动 |

返回 `1` = 已排队；`0` = 拒绝（限流/参数非法，当场知道）。排队后的请求在阶段二统一处理，以下情形作废（返回值已经是 1，**以运行日志为准**）：

- **位置起点限制**：出生点必须在你本拍快照坐标 **±10 格**内（每轴），防远程投射刷屏。y < ground(x)（钻地，D-016 地面高度数组）与 NaN 坐标同样拒绝。
- **限流**：每实体每拍最多 1 个 spawn 请求。
- **你已死**：本拍 `life()=false` 的创造者请求作废。
- **世界实体上限**：默认 64（`CODEWORLD_MAX_ENTITIES` 可调），达上限拒绝。
- **编译失败**：造物 WAT 编不合法 → 该次作废 + 警告，世界不崩。
- **出生点身体重叠**（decisions.md #030 半径物理，取代 #021 一格一物）：造物身体与任何存活实体身体（圆/方块）重叠 → 该次 spawn 失败，造物不诞生、不占世界名额，下一拍可重试。**身体判据按 motion 分流**：static=出生格对齐 1×1 AABB；dynamic=声明 `radius` 的圆。

造物属性（框架定，改不了）：owner 继承你的 owner（**产权链**，见 `destroy`）；fuel 配额继承你；出生即存活。

### `birth_blob(ptr: i32, cap: i32) -> i32`

出生数据包读回（第 13 个 import，2026-10-21 落地，与 `spawn` 第 13/14 参配套）：造物出生时母体塞进你沙箱的"家书"（≤ 64KB），出生后随时读回。母体传讯、代际遗传（母体的战术参数/地图记忆传给子代）从这一个原语长出。

- **三态返回**：`0` = 无包（玩家进场与弹丸恒此路径）；正 `N` = 已原子写入 `[ptr, ptr+N)`，返回包字节数；负 `-N` = 失败未写一字节——容量不足或指针非法（`N` = 包长，按它重新分配缓冲再读），日志区分两种原因。
- **原子写**：能整体放入才写——不会写半截留给你一份截断的家书。
- **生命周期**：随造物沙箱存活，跨重启不保留；可重复读（数据只读副本，读不消耗）。
- **世界不解释内容**：世界只搬运字节——通道归世界、内容归玩家（修路不跑车的数据版，#038 哲学同款）。

```wat
(import "env" "birth_blob" (func $birth_blob (param i32 i32) (result i32)))
(memory (export "memory") 1)
;; 家书区：预留 64KB 读回缓冲（地址 70000 起，避开常用低地址段）
(func (export "on_tick")
  (local $n i32)
  (local.set $n (call $birth_blob (i32.const 70000) (i32.const 65536)))
  (if (i32.lt_s (local.get $n) (i32.const 0))
    (then ;; 负返回=失败：容量不足或指针非法，-N 即包长，按 N 重分配后可重读
      (i32.const 42) (call $log))))
```

### `destroy(id_lo: i64, id_hi: i64) -> i32`

销毁（门二）：把目标 EntityId（128 位 Uuid 拆成两半，`id_lo` 为低 64 位、`id_hi` 为高 64 位；WAT 侧负 i64 会按位恢复成 u64，写 `-1` 就是 `0xFFFFFFFFFFFFFFFF`）提交销毁请求。

**产权约束**：只能销毁**自家造物**——框架在阶段二比对目标 owner 与你的 owner，不匹配拒绝 + 警告（MVP 规则；"击杀掠夺式"销毁走 `attack_at` 攻击通路，不归 destroy）。**destroy 不触发掠夺**——它不是击杀（铁律：掠夺只属于击杀）。想自尽走 `life()` 返回 0。

返回 `1` = 已排队；产权校验结果在阶段二，拒绝以运行日志为准。销毁的实体随后按死亡流程清理（下一拍从世界移除）。

```wat
(import "env" "destroy" (func $destroy (param i64 i64) (result i32)))
;; 销毁 id 高半 = -1（即 0xFFFF...）、低半 = 0x0102030405060708 的自家造物
(i64.const 0x0102030405060708) (i64.const -1) (call $destroy) (drop)
```

### `field_pulse(x: f64, y: f64, vx: f64, vy: f64, radius: f64) -> i32`

力场脉冲（D-012 交付物 8，第 15 个 import，2026-10-22 落地）：以 `(x, y)` 为中心、`radius` 为半径的圆域内，给所有**带速度实体**（弹丸 + dynamic 造物 + 任何 velocity≠0 的实体）的速度一次性加上 `(vx, vy)`——物理推，不是规则层。**这就是分离式发射器**：存量炮弹（spawn 出来的 dynamic 造物）+ 炮身（场造物）每拍 pulse 推膛内炮弹——D-018 shoot 退役的物理路初速来源。

- **推不动静止的**：velocity≡0 的实体无效（物理推是速度叠加；把人撞开是 D-010 碰撞冲量的事，另一个原语）。
- **推完照常受世界极速钳制**（归一化压回，方向不变）；场不认人——无所有权豁免，推到谁都一样推。
- **校验五条**：x/y/vx/vy 有限；冲量模长 ≤ 世界极速 25（严格 `>` 拒绝，恰等放行，与 spawn 初速同口径）；radius 钳 [0.1, 25.0]（超界钳回不拒绝）；`(x, y)` 必须在你本拍快照 **±10 格**内（防远程）；每实体每拍 1 次（与 spawn 同款限流）。
- **时序**：import 只排队，本拍阶段二统一应用（排在弹道步之前——本拍被推的弹丸照常参与积分，推膛内炮弹当拍出膛）。返回 `1` = 已排队；`0` = 拒绝（限流/参数非法）。

```wat
(import "env" "field_pulse" (func $field_pulse (param f64 f64 f64 f64 f64) (result i32)))
;; 在自己脚下 3 格半径内向前推一把（给膛内的炮弹上膛）
(f64.const 0.0) (f64.const 0.0)    ;; 脉冲中心 = 自己位置附近（±10 格内）
(f64.const 8.0) (f64.const 0.0)    ;; 冲量 (8, 0)，模长 8 ≤ 极速 25
(f64.const 3.0)                    ;; 半径 3 格
(call $field_pulse) (drop)
```

### `bridge_send(port: i32, ptr: i32, len: i32) -> i32`

外桥发信（D-001b，第 16 个 import，2026-10-22 落地；机制全貌见 design-bridge.md）：把一封信送进世界邮筒——世界以自己身份把信 HTTP POST 给 `port` 对应的外部服务器（你在 `bridges.json` 登记的端点），回信下一拍经 `bridge_on_reply` 投回。**世界只当邮差**：不解释信、不代存、不重试、不看内容。

- **port 是保险库别名，不是 URL**——你的沙箱内存里永远不会有服务器地址和凭证（铁律①，夺舍者只知道"有个 1 号端点"）；HTTP 由世界进程代签发出，登记的鉴权头世界贴上、沙箱看不到。
- **异步跨拍**：返回 `0` 只表示"信进了邮筒"，不表示送达/已回复（外部服务器处理要时间，理想 N+2 拍读到回信）。
- **返回码**：`0`=已排队；`1`=无此端点（port 未登记）；`2`=payload 超限（上限 8KB，`CODEWORLD_BRIDGE_PAYLOAD_MAX`）；`3`=本拍已发（每沙箱每拍 1 发）或在途满（上限 4 条，`CODEWORLD_BRIDGE_INFLIGHT`）；`4`=桥未启用/已吊销（世界没开 `CODEWORLD_BRIDGE=1`）。多重违规按 4→2→1→3 判序返回。
- **内存读取**（同 attack_at）：`len<=0` / 无 memory export / 越界 → 空 payload 照常排队（空信也是信）。
- **护栏全是工程保险丝**（防灌爆/防卡世界，与 fuel 同性质）：payload 8KB/信、每拍 1 发、在途 4 条、出站超时 5 秒（超时不投递，代码自管"发过没回声"，世界不重试）。MVP 客户端=手搓 HTTP/1.1 短连接，端点仅支持本机回环 http（127.0.0.1/localhost）；https 真客户端挂起（design-bridge §2.8）。客户端局限：不支持 Transfer-Encoding: chunked——回信需带 Content-Length 或靠短连接 EOF 收尾。
- **离线退路**：无端点/桥未启用 → 返回失败码，代码跑本地降级逻辑——离线=本体基础功能照跑，在线+外接=体系满血，降级策略归你。

```wat
(import "env" "bridge_send" (func $bridge_send (param i32 i32 i32) (result i32)))
(memory (export "memory") 1)
(data (i32.const 0) "WHERE?")
;; 每拍向 1 号端点发一封 6 字节的信；返回码 0=进了邮筒
(i32.const 1) (i32.const 0) (i32.const 6) (call $bridge_send)
```

**信封格式**（世界发出去的 HTTP body，你的外脑服务器解析用；内容字段玻璃不透明）：

```json
{"world":"codeworld","entity":"330132021716898259065734489702934923585","port":1,"seq":17,"payload":[87,72,69,82,69,63]}
```

`entity`=发起实体（**十进制字符串**——u128 数字在 JSON/JS Number 装不下，parse 回整数对账）、`port`=端点别名、`seq`=单实体单调递增序号（对账/去重用）、`payload`=你发的原始字节。世界侧日志只记 entity/port/seq/字节数/端点 url（url=保险库登记内容，非信件内容，单机无泄露面），**信内容零入日志**。

### `bridge_on_reply(port: i32, ptr: i32, len: i32)`（可缺省导出）

外桥收信（D-001b）：世界收到外部服务器的 HTTP 响应 body 后，下一拍 collect 阶段调用此导出——回信字节已由世界 **grow 新页**写进你的线性内存（`ptr`=新页偏移，`len`=回信字节数，新增零页永不覆盖你的数据；与 D-012 场信箱的"末尾保留段"不冲突：信箱是世界保留区约定，回信是 grow 追加区）。`port`=当初发信的端点别名。

- **缺省导出 = 收不到回信**（世界零副作用丢弃+日志）——不要回信的生物不导出即可。
- **死亡竞态诚实条款**：信件在**世界出站时点**仍需你存活——出站前死亡（含同拍自尽）→ 信作废不送（INFO 日志）；已出站的信照飞不撤（载体不存活≠消息没发出）；回信抵达时你已死 → 回信丢弃。超时/非 2xx 不投递——超时逻辑你自己的代码管（"我发过 seq=17 没收到回声"自己记）。
- **投递时点固定在拍边界**（确定性锚）：回信到达时刻在拍中任意点，但调用固定在下一拍 collect 阶段。
- **独立小预算包裹**（默认 10_000 指令，同 probe/on_contact 档 `CODEWORLD_PROBE_FUEL`）——回信处理不占你的 tick 配额，恶意死循环最多烧预算。
- **不做** bridge_poll/bridge_status（回信即投递无需轮询；诊断=发一封"你活着吗"的信自己问）。

```wat
;; 收信：扫回信字节找第一个 ASCII 数字当指令（demo 全文见 players/bridge-demo.wat）
(func (export "bridge_on_reply") (param $port i32) (param $ptr i32) (param $len i32)
  ;; f32/f64 无关——回信是任意字节，怎么解释是你的事
  ;; 例：数字 3 = 连走 3 拍向东（外脑回 {"dx":3}）
  ...)
```

## 二点四、世界内链路段（D-011）——链是活电话，契约是遗嘱，存储是公开信箱

**法律事实**（#038 通道公理世界内段）：链/消息/存储三件套全部落在**信息通道**层——世界只送信不拆信，全部零内容解释。外桥=对世界外出线（`bridge_send`）；本节=世界内管道。两个管道、同一法条。直接访问仍然只有物理接触→决斗会话一条路——本节接口全部**不触碰对方沙箱内存**：send 送的信对方自愿收（开门=导出回调），storage 读的是世界侧公开块非沙箱内存。

**链三态**：无链（放生，spawn 默认）/ 活链（可控+可传）/ 断链（孤儿按 binding 契约活）。`link` 与 `binding` 正交自由组合：链管通信、契约管生死——可自由组合（link=1+binding=0：母体死后造物活着但链断了；link=1+binding=1：母体死当拍同生+链断无感）。**广播制寻址**：command=向名下全部活链造物广播，不做"第 N 个孩子"编号寻址——沙箱不持久化记不住编号，谁响应哪条指令是玩家代码的事（指令内容带标记孩子自己过滤，世界零预设）。

### `command(ptr: i32, len: i32) -> i32`

下行广播（母体剑诀控万剑——飞剑剑诀本来就是万人一面）：把 payload 从你的 memory `[ptr, ptr+len)` 读取，排队投给**名下全部活链造物**（link_to==你 且 存活），对方经 `on_command(offset, len)` 收到。

- **返回码**：正数=入队链数（本拍开始时名下活链孩子数）；`0`=无活链或参数坏（len 超上限/本拍已广播）。多重违规按超限→限流→无链判序。
- **每拍 1 次**；**无视口限制**（链=声明关系，风筝线可放出屏幕——风筝流成立前提）。
- **两拍节律**（与外桥回信一致）：拍 N 你 command，拍 N+1 阶段二投递（孩子 on_command 被调），孩子主代码拍 N+2 on_tick 感知。孩子当拍死了=丢弃+INFO（无人认领）。
- **fuel**：调用本身烧你的 tick 燃料；孩子的 on_command 烧**孩子的**独立防守预算（probe 同档 10_000，不占它主配额——围殴经济学：发信烧自己，收信有独立上限兜底）。

```wat
(import "env" "command" (func $command (param i32 i32) (result i32)))
(memory (export "memory") 1)
(data (i32.const 0) "TURN+2")   ;; 剑诀内容自己定义——世界不解释，孩子自己过滤
;; 广播给全部活链造物；返回 3 = 名下三个活链孩子已入队
(i32.const 0) (i32.const 6) (call $command)
```

### `report(ptr: i32, len: i32) -> i32`

上行沿链（侦察弹报坐标）：你是活链造物时（link_to 有值），payload 沿链投给母体，母体经 `on_report(from, offset, len)` 收到。**无需寻址**——链连着呢，世界查账本找母体。

- **返回码**：`1`=入队；`0`=参数坏（len 超上限/本拍已上报）；`2`=无链或断链。
- **`from` 参数**=发送造物 EntityId 低 64 位（8 字节小端，i64 直传）——母体多孩子区分靠它；孩子自己的状态写进消息内容。
- **每拍 1 次**；无视口限制。母体当拍死了=信丢弃+INFO（濒死回传天然成立：消息发出≠载体存活——反过来，载体死了信照送）。
- 同族回调 `on_message` 同签名同预算（见 `send`）。

```wat
(import "env" "report" (func $report (param i32 i32) (result i32)))
(import "env" "get_pos" (func $get_pos (result f64 f64)))
(memory (export "memory") 1)
;; 每拍把自己的坐标上报给母体（16 字节 = x/y 两个 f64）
(func (export "on_tick") (local $x f64) (local $y f64)
  (call $get_pos) (local.set $y) (local.set $x)
  (f64.store (i32.const 0) (local.get $x))    ;; x 写 [0..8)——f64.store 先地址后值
  (f64.store (i32.const 8) (local.get $y))    ;; y 写 [8..16)
  (i32.const 0) (i32.const 16) (call $report) (drop))
```

### `send(x: f64, y: f64, ptr: i32, len: i32) -> i32`

横向数据通道（坐标寻址，与 probe/attack_at 同哲学——点寻址，所见即所发）：把 payload 投给坐标 `(x, y)` 处的视口内实体，对方经 `on_message(from, offset, len)` 收到。

- **视口门槛**：目标必须在你的**视口内**（visible 列表成员——"屏幕内无欺骗"的发送版：看不见的发不到，想发先 scan/visible_at 拿坐标）。坐标精确匹配（visible_at 给出什么就发什么）。
- **返回码**：`1`=入队；`0`=参数坏（坐标非有限/len 超上限/本拍已发）；`-1`=坐标无实体或不视口内。
- **每拍 1 次**。对方聋（无 on_message 导出）=入队成功但投递作废+INFO（**通信自由=发信自由；开门=收信自由**，注入无门落地）。
- **不做**（接口面最小化）：送达回执（消息发出≠送达，代码自理）；广播 send（广播=自己循环坐标发）；视口外投递（跨视口走链或外桥——横向中继=自己拼信鸽，storage 块就是给这个的）。

```wat
(import "env" "send" (func $send (param f64 f64 i32 i32) (result i32)))
(import "env" "visible_at" (func $visible_at (param i32 i32 i32) (result i32)))
(memory (export "memory") 1)
(data (i32.const 0) "HELLO")
;; 拿 0 号可见实体的坐标发信（先 visible_at 取坐标，再按坐标投）
(i32.const 0) (i32.const 100) (i32.const 108) (call $visible_at) (drop)
(f64.load (i32.const 100)) (f64.load (i32.const 108))
(i32.const 0) (i32.const 5) (call $send) (drop)
```

### `storage_write(ptr: i32, len: i32) -> i32` / `storage_read(x: f64, y: f64, ptr: i32, cap: i32) -> i32`

公开存储块（造物=移动硬盘）：`storage_write` 全量覆盖**自己的**公开块；`storage_read` **贴身**读对方的公开块（距离 < 你的半径 + 对方半径 + 0.5 严格小于——读硬盘=物理凑过去读，与 melee 判距同款）。**数据在世界侧**：不烧沙箱燃料、不占沙箱内存、**随实体入快照（重启不丢=比沙箱内存耐用）**。信鸽中继玩法：前线造物写盘 → 飞越战场 → 后方母体贴身读走。

- **storage_write 返回码**：`N`=写入字节数（全量覆盖，写 0 字节=清盘）；`-1`=超容拒绝（**不截断**——硬盘写一半=坏盘，诚实拒绝；上限 4096B，`CODEWORLD_STORAGE_CAP`）；`0`=参数坏（负长度/本拍已写盘）。
- **storage_read 返回码**：`N`=读到字节数（写入你的 memory `[ptr, ptr+N)`，原子）；`0`=cap 不足或指针坏；`-1`=坐标无实体；`-2`=够不着（贴身判据外）；`-3`=对方无存储（**空块同返 -3**——没写字的盘=世界视角无存储，不另设"空盘 0"码）。读自己：storage_read 自己坐标（get_pos），距离 0 天然成立，读自己的盘（同拍写后读可见新值）。
- **每拍各 1 次**（写与读各一，写读同拍可并用）。失败路径不占限流（下一拍可重试）。
- **与"接触传导"挂起项的区分**：storage_read=主动 import 拉读世界侧公开块（信息通道层），不触碰对方沙箱内存——飞剑回鞘（接触自动连通沙箱内存）是另一层另议。
- 完整立法（否决编号寻址/链上写盘/送达回执/视口外投递/世界侧持久化）见 decisions.md；演示对见 `players/link-demo.wat`（风筝演示：母体广播转向+侦察弹回报坐标）。

```wat
(import "env" "storage_write" (func $storage_write (param i32 i32) (result i32)))
(import "env" "storage_read" (func $storage_read (param f64 f64 i32 i32) (result i32)))
(memory (export "memory") 1)
;; 前线造物写情报（全量覆盖）
(i32.const 0) (i32.const 6) (call $storage_write) (drop)
;; 后方母体贴身读对方硬盘（cap 512 的缓冲；返回 N=读到 N 字节，-2=凑近点再来）
(f64.const 7.0) (f64.const 8.0) (i32.const 2048) (i32.const 512) (call $storage_read)
```

### `on_command(offset: i32, len: i32)`（可缺省导出）

造物收母体剑诀：母体 command 的信字节已由世界 **grow 新页**写进你的线性内存（`ptr`=新页偏移，`len`=信长，新增零页永不覆盖你的数据）。不带 from 参——链连着呢，你知道信是谁的（谁响应哪条指令是你的代码写的）。缺省导出=收不到信（世界零副作用丢弃+日志）。

### `on_report(from: i64, offset: i32, len: i32)` / `on_message(from: i64, offset: i32, len: i32)`（可缺省导出）

母体收孩子回传 / 任意沙箱收横向信。`from`=发送方 EntityId 低 64 位（母体多孩子区分靠它）。投递时点=拍边界（下一拍阶段二，确定性锚）；独立小预算包裹（默认 10_000 指令同 probe 档）——收信不占你的 tick 配额，恶意来信烧不动你的主算力。缺省导出=聋（合法，通信自由是双向的）。

**快照注意**：链消息不进快照——在途消息=当拍生命周期，重启即清（持久化归存储块：要留的字段自己 storage_write 落盘）。

## 二点五、力场（D-012）——场是出生声明，不是特殊品类

**法律事实**：场 = 造物的一种出生声明（`field_radius`/`field_gravity_scale`/`field_drag_delta`，与 radius/mass/binding/motion 并列）——**"场造物"作为特殊品类在法律上不存在**，世界只认声明不认身份。场源=物理身体（能被攻击、能被夺舍、死了场即消失），效果=参数改写区（无形体：不占位、不拦截碰撞、不挡路）。

- **叠加 v2（代数抵消+域钳制）**：域内生效重力 = 世界重力 × 域内各场 gravity_scale **乘积**；生效阻力 = 世界阻力 + Σ各场 drag_delta（**代数和**：+2 与 -2 归零，对冲场是真实战术）。域钳制兜底：重力 [-98.0, 0.0]、阻力 [0.0, 25.0]——堆场买不到定律外胜利。账本不认老板：所有场一律入账，无所有权标签；自伤真实（场不认人，豁免是你自己代码写的）。
- **位移通道同吃（FIX-1 场不认人）**：域内**一切移动**按阻力改写量衰减位移——角色行走/操控位移/env.move_by 排队的 SetPos 与弹丸速度通道同一法律，无豁免名单（世界默认场内全吃，豁免是场代码自己写的）。衰减因子 = `1 − drag_delta_eff / mass`（drag_delta_eff = 域内各场 drag_delta 代数和的钳制值 [0, 25]；**世界默认阻力 0.05 不进位移账**——否则无场世界步长也会缩水，破坏零回归）；因子 < 0 钳 0（糖浆场 delta ≥ mass 时寸步难行）。对冲场（负 delta）最多抹平衰减，不许反向加速；aloft 零位移悬停步不受影响。
- **成型期**：诞生后 3 拍（`FIELD_FORMING_TICKS`，`CODEWORLD_FIELD_FORMING` 可调）场不结算物理（可穿过）但已可见——前端虚线环=成型中、实线环=已成型，给进攻方反应窗。
- **每拍重算**：场的覆盖关系每拍全量重算（没有 enter/exit 事件缓存）；域判定 = 实体坐标与场源的圆心距 < field_radius（简单确定，与身体碰撞无关）。场快照取**拍初**（本拍移动应用之前收集）——位移/速度两通道看同一份快照；移动的场源域心滞后一拍、本拍被销毁的场源多生效一拍（有界一拍级，拍初一致性取舍）。
- **零计费**：场的成本 = 普通造物日常开销 + 实体名额。世界不向场收一分税（无负载费、无底租——防守方因被攻击而破产是荒谬定价，世界给玩法定价违宪）。
- **可视铁律**：场必须可视（快照协议 `fields` 数组，半透明圆环 telegraphing——所见与所判一致）。aloft（悬停）优先级高于场：悬停声明本拍免重力，场不覆盖它。
- **极速不改写**：本刀场只改重力缩放与阻力，极速场未开放（极速是世界视觉可读性常数，保守起步）。
- 完整立法（判例/反制五路/智能场哲学）见 decisions.md #040/#051；参数细节见上文 spawn 第 15/16/17 参与第一节 `on_field`。

## 二点六、液体（D-009）——水是出生声明，浮沉是公式涌现

**法律事实**：液体 = 造物的一种出生声明（`liquid_density`/`liquid_drag`，与 radius/mass/binding/motion/field 并列）——**"液体造物"作为特殊品类在法律上不存在**，世界只认数字不认名字。"油 0.75 / 盐水 1.1 / 蜂蜜 1.4 / 岩浆 2.5"是**社区预设黑话**（官方示例密度表），不是世界内置清单（#011 反面教材 = MC 硬编码浮沉名单）。你造 ρ=0.8 的"蓝油"世界不拦不判。

- **液体造物三条特性**：①纯布景无沙箱——出生跳过沙箱创建（液体是物理域不是居民），但照常占世界实体名额（防刷水弹幕），WAT 编译照常跑（spawn 合法性校验）；②水不会动——无视 motion 声明强制 static（格对齐 AABB 即水域边界），不做守恒水体（不流动不搬运，MC 1.13 教训）；③照常被 scan/probe 探测（布景与规则分层，WC3 先例）。
- **浮沉全公式涌现（零特例无清单）**：域内实体浸入比 f（竖径夹逼近似，0=擦边/0.5=圆心在液面/1=全浸没）→ 浮力改写重力 `g_final = g × (1 − ρ液/ρ物 × f)`，钳 [-98, +98]（浮力档对称十倍域——与力场档 [-98,0] 不同，浮力恰恰要向上）。ρ物 = m/(π·r²)（推导密度，密度不出生声明）。ρ物=ρ液 全浸 → 悬浮；ρ液>ρ物 → 上浮（木）；ρ液<ρ物 → 缓沉（铁）。力场重力×0 的域内浮力也消失（浮力源于重力，物理自洽）。
- **水中阻尼（MC 次序）**：水中一步 `v ← v×k_eff + g_final`（速度先乘保留系数再加净加速度），k_eff = clamp(k, 0, 1)。k=0.35 → 入水一拍速度掉 65%。
- **附加质量（独门立法）**：`m_eff = m + ρ液×π×r²×f`（2D 圆解析解=排开流体质量）——进阻力分母（质量大阻力影响小），"水下加速钝"从阻力响应涌现，零新参数。ρ物 计算用真实 m 不用 m_eff（防递归）。
- **多域取最高密度**：实体同时泡多个水域 → 取 ρ 最高者结算，k 取同域配对值（ρ 与 k 是同一造物的配对声明）。aloft（悬停）优先级高于浮力：悬停声明本拍免重力免浮力免阻尼。
- **"我在水里"没有专属事件**（感知环境→切换行为=玩家代码通用范式）：scan 探到液体造物 + 自己坐标落在它 AABB 内 = 你在水里。岸上/入水/半沉/全浸没/出水五态状态机是玩家的功课。（挂起：世界生成器出生水域+官方示例活水归"出生地形多样化"后续刀。）
- **可视铁律**：水域必须可视（快照协议 `liquids` 数组：`{x,y,w,h,density}` 矩形；前端按密度查表插值画色——0.75 淡黄/1.0 蓝/1.4 琥珀/2.5 橙红，纯装饰非世界事实）。
- **零计费**：液体成本 = 普通造物日常开销 + 实体名额。世界不向水收一分税。
- 完整立法见 decisions.md #053；参数细节见上文 spawn 第 18/19 参；示例见 `examples/liquid-demo.wat`。

## 三、进场：players/ 目录（门一）

- **一个 `.wat` 文件 = 一名玩家。** 把文件放进 `players/` 目录（默认 `./players`，`CODEWORLD_PLAYERS_DIR` 环境变量可改）即进场，删除文件即下线。
- **玩家名** = 文件名去扩展名（`pioneer.wat` → 玩家 `pioneer`），也是你在世界里的身份标识（me 声明操控身份用的就是它，见第七节）。`_` 前缀文件与 `.txt` 后缀不进场（`_template.wat.txt` 是不会启动的模板）。
- **字形** = 玩家名首字符大写；**颜色**按进场顺序从 green 轮转（green → magenta → blue → red → cyan → yellow → purple 回绕；红/青/黄/紫已被开局四生物占用）；**出生点** x 在 30 / 35 / 40 / 45 循环，y = 0（平地地面线；起伏地形世界同样从 y=0 出生，物理步会把你落到地面）。进场即得满额生存点数（见「五点二、生存点数」）。
- **开局四生物**（MVP 剧本实体，非玩家）：`A` 红（attacker——scan 锁最近敌人、接近出刀）、`D` 青（defender——on_attack 有盾拦截，盾量 `CODEWORLD_D_SHIELD` 配置默认 10）、`H` 黄（hunter——每 8 拍投掷一发一体式造物弹，两拍回弧）、`S` 紫（spy——右侧高空悬停的伪装者，on_probe 撒谎+盾 3 次拦截，盾尽放行）。空世界自动登场；`CODEWORLD_H_ENABLED=0` / `CODEWORLD_S_ENABLED=0` 可只留 A/D 经典对局。它们与玩家同规则（可被杀可被掠夺）。
- 世界运行中每拍轮询目录：运行中途放入新文件 = 当拍进场。
- **下线语义（残影期）**：删除文件后你的角色不会立刻消失——它进入残影状态，在世界里留 **5 拍**，期间不执行你的代码（不再动、不防守），但**可以被攻击、被击杀、被掠夺**。5 拍后消散。
- **战斗残影期（不可豁免）**：如果你在最近 **30 拍内参与过战斗**（出刀或挨打都算），残影期不是 5 拍而是 `max(5, 30 - 距最近参战拍数)` 拍——临战拔线躲不进安全期，残影期内被杀照常被掠夺。
- 编译失败的 `.wat`：记警告跳过，世界不受影响；**删除文件再重新放入**可重试。
- 同名文件重写内容**不生效**（MVP 无热更新）：想换代码，删掉文件再放。
- 角色被击杀后文件仍在：不会自动重生（死亡是真死亡）。删除并重新放入文件，即以新角色进场。
- **世界重启**：玩家角色不跨重启——重启后世界从快照恢复时，你的旧角色实体只剩元数据（无沙箱、不跑代码、不可操控，但仍占实体名额、可见、可被打）；`players/` 里的 `.wat` 会让世界按普通进场流程给你**新开一具身体**。想要"干干净净一局"，关世界时删掉 `codeworld.db`（start.bat 有提示）。

## 四、三张合同（存在性语义简表）

你的角色默认签**在线锚合同**：文件在 = 在线，文件删 = 经残影期消失。完整设计见 `docs/world-foundation.md` 第三章。

| 合同 | 锚 | 默认谁用 | 语义 |
|---|---|---|---|
| **在线锚** | 你的在线信号（players/ 文件） | 玩家角色 | 上线存在，下线经残影期消失 |
| **自治锚** | 实体自己的代码 | 花/建筑/NPC | 寿命/死亡规则写在自己代码里 |
| **连接锚** | 外部端点连通性 | 阵法/AI-NPC | 在线获实时注入，断连降级本体逻辑 |

合同可组合、归玩家定义；框架唯一的强制底线就是上面的战斗残影期。

## 五、攻击语义铁律（#001 摘录）

1. 攻击只伤**代码**（裸奔刀换血收尾 / 游魂改写守方内存——D-005 刀0 起主路径）与**算力**（防守烧 fuel、游魂烧攻方赌注），不碰生存点数。
2. 生存点数唯一变动路径 = 时间衰减 + 击杀掠夺。
3. 血条只存在于渲染层，数据模型里没有血量。
4. **掠夺只属于击杀**——没有击杀就没有掠夺，无吸血式设计。

## 五点一、决斗制（D-005 刀0）——命中=开战，世界只当硬件

非空 payload 的攻击不再换血（decisions.md #046/#047 已入宪，design-duel 定案）：命中 = 世界给双方插一根**内存映射数据线**，你的游魂以自己的燃料赌注在守方内存里持续读写数拍，胜负全由双方代码定——世界只记录机械事实（油尽/崩溃/实体死亡），不判胜负。

**游魂窗口契约**（你的模块要带的东西）：

```wat
(import "env" "duel_read"  (func $duel_read  (param i32 i32 i32) (result i32)))
(import "env" "duel_write" (func $duel_write (param i32 i32 i32) (result i32)))
(import "env" "duel_round" (func $duel_round (result i32)))
(memory (export "memory") 1)
(func (export "on_duel") (result i32) ... (i32.const 1))  ;; 返回 1=宣布完成收尾，其他=继续
```

| 原语 | 语义 |
|---|---|
| `duel_read(ptr, len, out_ptr) -> i32` | 读守方线性内存 `[ptr, ptr+len)` → 写进**你自己的** memory `[out_ptr, ...)`；返回实际字节数；越界/指针非法返回 `-1` |
| `duel_write(ptr, bytes_ptr, len) -> i32` | 把**你自己的** memory `[bytes_ptr, +len)` 写进守方内存 `[ptr, ...)`；返回写入字节数；越界返回 `-1` |
| `duel_round() -> i32` | 当前窗口拍号（0 起，做轮次策略用） |
| `on_duel() -> i32` | 每拍窗口被世界调用一次；返回值即投票：`1`=宣布完成（会话正常收尾），其余=继续 |

**游魂三铁律**：

1. **最小环境**：窗口内可调的 import 只有上面三个——`env.log`/`get_pos`/`spawn` 等一概没有，走私多余 import 的模块拒绝实例化=游魂崩溃。偷读到的字节只能留在你自己的 memory 里（随会话消亡——外传通道是玩家自己搭的桥，刀0 未开放）。
2. **账本跟人不跟房子**（decisions.md #046）：每窗口从你的**燃料赌注**扣 `duel_step_fuel`（默认 10_000，`CODEWORLD_DUEL_STEP_FUEL` 覆盖）；赌注=你出生时继承创造者的 fuel 配额（#047 继承制），**死油箱不重发**——守方油箱每拍重发而你不会，拖下去必先油尽被驱逐（防御成功），干完就收工最经济。
3. **崩溃即弃**：模块编译失败/实例化失败/缺 `on_duel` 导出/trap = 游魂崩溃，会话关闭，攻击作废（无击杀无掠夺）；赌注烧完=油尽驱逐。守方的 `on_attack` 拦截判定不变——拦截成功=你的游魂死在门外，会话根本不开。多游魂并存合法（同一守方多条会话各烧各的赌注，互不干扰——"世界开的是网吧不是擂台"）。

完整示例（读→带→写全链路 + 轮次收工）：`examples/duel-demo.wat`。设计全文：`docs/design-duel.md`。

## 五点二、生存点数——你唯一不能直接读写的硬数值

世界给每个存活居民配一本**生存点数账**（`SurvivalPoints`）。它是框架管理的唯一硬数值：**没有任何 import 能直接读它、改它**——它的变动路径只有两条（攻击铁律第 2 条的落地）：

| 路径 | 规则 | 常数 |
|---|---|---|
| **时间衰减** | 每过 86_400 拍（一个"游戏日"，1秒/拍=24小时）点数 -1；归零即死（"老死"） | `TICKS_PER_DAY = 86_400` |
| **击杀掠夺** | 你的刀杀死对方 → 从死者账上转 1 点给你（`transfer` 全有或全无：死者点数不足 1 时一分不转，双方不变）；`destroy` 与游魂会话**不触发**掠夺 | 每击杀 +1 |

- **出厂 3 天**：进场/造物出生时点数 = 3（`259_200` 拍）。不主动找吃的（掠夺别人）也不被杀，三天后自然死亡——这是世界逼你出门的原始动力。
- **fuel 不是生命**：指令配额（fuel）每拍重发 100 万条，是防死循环的保险丝，与生存点数两本账（工程参数禁入玩法）。
- **点数进快照**：随世界存档跨重启；血条式显示归前端渲染层。

## 五点五、资产段（#051 皮入沙箱）——沙箱三段论

沙箱=一个盒子，装三样：**代码**（引擎，wasm 模块）、**数据**（魂，线性内存+出生数据包）、**皮**（美术资产段，v2.4 快照 `asset_ids` 指纹）。三件套全在一个盒子里，**夺沙箱=夺全套**（decisions.md #051）。

| 语义 | 规则 |
|---|---|
| **装戴** | 资产段=asset_id 列表（`av_`+16hex，指向全局镜像仓；同图全局一份 sha256 去重，MC 同款）。数据非执行：不烧 fuel、不参与编译，只占沙箱内存边界 |
| **随行** | 皮随魂走：换血成功=资产随行进新沙箱（无拆分选项）；换血失败/超配额=旧沙箱原样保留（资产不丢）；沙箱死亡=资产段随沙箱亡（存在性同构：资产生命周期=沙箱生命周期） |
| **配额** | 配额账两源=引擎（模块字节）+皮（资产），默认 8MB（`SANDBOX_ASSET_QUOTA_BYTES = 8 * 1024 * 1024`，`CODEWORLD_ASSET_QUOTA` 覆盖，0/非法值回退默认）；魂（线性内存）走 64MB 内存上限独立账——两账并行。换血时新模块+随行资产超配额 → **拒绝换血，资产不丢**（夺取方装不下自己的 payload 那是夺取失败） |
| **改皮战术** | 攻破可改魂可换皮——接触通道（换血路径）本身就是写口：金龙旗改黑龙旗=占领宣示（"操纵比杀死值钱"的视觉版）。改皮零新 import（直接改沙箱资产段） |

出生装戴（玩家声明 asset 清单）归 spawn 参数化后续刀；本版资产段随沙箱存在、随换血随行、随死亡消亡。

直觉锚：配额管"盒子里装多少东西"，64MB 内存上限管"魂的房间多大"——两本账并行不混。完整立法（无私产/夺取不跨世界/连带作废私产方案）见 decisions.md #051；快照指纹下发与前端取图见 net-protocol.md v2.4 §9.4。

## 五点六、地形（D-016）——地面是一条高度曲线，不是一条直线

**法律事实**：地面从常量 `y=0` 升级为**高度数组** `ground(x)`（1D 均匀采样 + 线性插值，种子可复现）。所有"钻地判据"从 `y<0` 改为 `y<ground(x)`（move_by / spawn 出生点 / 物理落地同一口径）。平地世界（默认）`ground(x)≡0`，一切行为与旧世界零差异。

- **预设**：世界启动时选 `flat`（平地，默认）/ `hills`（丘陵）/ `mountain`（山地），`CODEWORLD_TERRAIN` 配置（收中文别名"丘陵/山地"）；`CODEWORLD_SEED` 种子（同预设+同种子必产同一张高度图）。**仅新世界生效**——从快照恢复的世界地形随快照走。
- **玩家侧可见影响**：`move_by` 目标若在地形线下（钻地）拒绝；spawn 出生点同理；物理步会把空中的你落到 `ground(x)` 线上。`y=0` 退位为坐标基准线（海平面语义），不再是地面。
- 想知道自己脚下多高：`get_pos` 拿坐标，地面高度本身**没有查询 import**——地形信息要走视觉（前端画了地形折线）或自己记忆/探测（零新原语）。

## 五点七、浏览器与操控通道（期四/期五）——世界是服务器，浏览器是遥控器

世界进程同时是一个 HTTP/WS 服务器（默认 `127.0.0.1:8080`，`CODEWORLD_WS_PORT` 覆盖，0=禁用）：

- **`http://127.0.0.1:8080/`**：自带静态页（Canvas 画面 + 鼠标操控），世界启动即可开浏览器玩。
- **`/ws`**：WebSocket——下行每拍全量快照 JSON；上行操控意图。**第一个连接=操控端**，后来的连接=观战（上行丢弃）。协议字段全表见 `docs/net-protocol.md`。
- **上行意图五型**（JSON，`{"type":...}`）：
  - `{"type":"move","x":..,"y":..}` 点地/点空走路（矢量步进，走到自动停；空中点=飞行）
  - `{"type":"attack","x":..,"y":..}` 对坐标出刀（贴身距离内才成立）
  - `{"type":"shoot","x":..,"y":..}` 远程射击（超贴身距离点中实体时前端自动改发此型；世界解算弹道 spawn 造物弹，每拍 1 发；无解（够不着）不发射+日志明示）
  - `{"type":"stop"}` 站住（空中=悬停不坠）
  - `{"type":"logout","disposition":"take"|"stay_auto"|"stay_ai"}` 登出三选一（见下）
- **操控优先于自主**：你发意图的拍，你的角色 `on_tick` 被跳过（这拍完全听你的）；没发意图的拍回落代码自主。操控不豁免物理（照常碰撞裁决/两阶段结算/极速钳制）。
- **操控权=me 声明**（不是"谁连上谁操控"）：世界按 `CODEWORLD_ME`（优先）或 `players/me.txt` 里写的玩家名，把操控端意图路由给该角色。声明无效/未声明=观战。
- **登出与断线（#025 下线处置权）**：WS 断开 ≠ 角色消失——进入**处置等待**（默认 30 拍，`CODEWORLD_DISPOSE_WAIT`，0=立即带走），超时默认带走；主动登出三选一：
  - `take`：带走（会话级离场：实体移除，文件锚仍在，重连或下次扫描以新身体进场）
  - `stay_auto`：停留+自主接管（`on_tick` 恢复，挂机 AI 接管身体）
  - `stay_ai`：停留+等 AI（站桩；外部 AI 端点是未来能力，当前=站着可被打）
  - 等待期/AI 待接期是**活角色**：不跑 `on_tick` 但 `life()`/防守照常，可被杀被掠夺。`me` 重声明+重连=随时抢回操控（接管者被顶掉）。
- **终端键盘**（备用操控通道，与浏览器同一路由）：WASD/方向键移动、空格攻击最近可见敌人、`q`/Enter/Ctrl+C=**只关终端画面**（世界后台常驻，浏览器照玩）、`Q`（大写，3 秒内按两次）=真正关世界并存档。
- **世界常驻**：世界进程独立于任何终端窗口——关终端浏览器里世界照跑（Minecraft 专用服务器同款）。点终端窗口的 X 会杀进程（等同旧语义），正规关闭=Q 二段确认。

## 五点八、角色图上传（D-017 收图通道）——画一张图就是你的身体形状

`POST /upload/avatar`（multipart/form-data，与 WS 同端口）：

- **字段**：`file`=PNG 字节（必填）；`name`=角色名（必填，非空 ≤64 字节 UTF-8，中文合法）；`height_world`=世界高度格数（选填，默认 2.0，域 0.05..=25.0 钳制）。
- **护栏**：PNG ≤2MB；边长 ≤1024px；解码失败/连通性校验失败（断件图、全空图）拒绝。HTTP 恒 200，成败看 body `{"ok":true,"asset_id":"av_..."}` / `{"ok":false,"reason":"oversize|oversize_dim|decode_failed|isolate_fail|bad_json"}`。
- **产物**：`asset_id`（`av_`+16hex）进全局镜像仓；原图 `GET /assets/{asset_id}.png` 直取；128×128 布尔掩码随 WS 首帧 `avatar_assets` 消息下发。同图 sha256 去重（同图全局一份）。
- **掩码=判定**（#041 三位一体）：>50% 不透明算实心；连通性校验防断件；渲染与物理同源。当前版本：上传的图经前端按实体 radius 贴图渲染（皮渲染）；"生图即角色"的出生装戴声明（spawn 参数化挂资产）是后续刀——现阶段收图/仓/配额/随行换血管线已就位。

## 七、操控层 v0（终端键盘 + 浏览器鼠标，#022/#027）

双层玩家模型的第一块落地：**代码层**（你的 `.wat`，离线持续运转的挂机AI）之上叠加**操控层**（实时参与）。**主入口已是浏览器**（点地走路/点人出刀/点远处射击/登出三选一，见「五点七」）；本节终端键盘是同一路由的备用通道。操控通道是外部通道（#014）的首个应用——来源从"终端键盘"扩到"WebSocket 意图流"，路由（意图流/操控优先/物理裁决）不变。

### 键位表

| 按键 | 意图 |
|---|---|
| `W` / `↑` | 向北移动一步 |
| `S` / `↓` | 向南移动一步 |
| `A` / `←` | 向西移动一步 |
| `D` / `→` | 向东移动一步 |
| `空格` | 攻击最近可见敌人 |
| `q` / `Enter` / `Ctrl+C` | 关闭终端画面（世界后台常驻，浏览器照常操控——#036 期五） |
| `Q`（大写，3 秒内两次） | 真正关闭世界（存档+退出，二段确认防误触） |

按住方向键连续生效（键重复事件照收）；其余按键忽略。输入走 raw mode（按键即达、不回显、不等回车），画面画在终端备用屏（alternate screen），退出/panic 全路径还原你的 shell 现场。

### 意图语义（三条铁律）

1. **意图流，非坐标直写**：按键 = 排队一条本拍意图，tick 每拍开头统一消费。框架不瞬移你——操控移动照常走半径碰撞裁决（身体重叠分轴滑动，塔前停和代码层移动一模一样）；操控攻击照常走两阶段结算（收件 → 定序结算，该被拦截照样被拦截）。**操控不豁免物理。**
2. **操控优先于自主**：你按键的那一拍，你的角色代码 `on_tick` 被跳过（自主移动/攻击都不跑，这拍完全听你的）；没按键的拍回落代码自主（= 挂机AI照常运转）。你的 `life()` 每拍照常执行——存在合同不受操控影响。同拍多键按到达顺序折叠，**最后一键说了算**。
3. **谁被操控（#024 身份绑定）**：操控权 = **身份声明**，不是进场顺序。你声明自己的名字（`CODEWORLD_ME` 环境变量优先，其次 `players/me.txt` 一行内容），世界每拍校验该名字是否已进场在线，是则操控它。

### me 声明语义表

| 状态 | 判定 | 行为 |
|---|---|---|
| 声明有效 | 声明的名字已进场在线 | 操控该玩家：按键接管、字幕 `ctrl:字形`、实体白色高亮 |
| 未声明 | `CODEWORLD_ME` 与 `me.txt` 都没有 | **观战模式**：按键仅 Quit 生效（移动/攻击键提示一次不刷屏），字幕 `ctrl:--`，无高亮；世界照常运转 |
| 声明无效 | 名字拼错/未进场/已下线 | warn 一次 + **观战模式**（同上）；名字后来进场则自动生效（每拍解析，`me.txt` 中途创建/修改也生效） |

**操控目标下线**（删玩家文件）：warn 一次 + 自动转观战，字幕 `ctrl:--`；**重新进场不自动恢复操控**（会话已断，需重启或期四动态恢复）。`CODEWORLD_ME` 为空串视为未通过环境变量声明，回落 `me.txt`。

### 操控攻击

空格对**最近可见敌人**出刀（与 `scan` 同一视野口径：屏幕内才算看得见）。空 payload 默认击杀刀，走你熟悉的收件/结算流程——防守方的 `on_attack` 照常询问，出刀即参战（战斗残影期照算）。视野内没有敌人 = 挥空（本拍不出刀，但操控仍接管该拍）。

浏览器侧另有**远程射击**（`shoot` 意图）：点中实体但超出贴身距离时自动改发——世界解算器算初速后 spawn 一发**定装造物弹**（小圆点 dynamic 造物，从身体边缘出膛），命中归接触通道代码攻。每拍 1 发；无解（够不着）不发射+日志明示；走位目标不清（边走边射）。操控射击是"驾驶档"：参数世界定，想要自定义弹道走玩家代码 spawn 出生初速（`docs/newbie-first-thrower.md` 第一课）。

### 视觉反馈

- **字幕**：有玩家在线即显示 ctrl 段——操控中 `ctrl:P`（P = 玩家名字形），观战 `ctrl:--`（区分"无人"与"有人但不是你"）；无玩家在线不显示该段。如 `tick=5 | A->D dist=2.4 | D shield=7 | alive=3 | ctrl:P`。
- **高亮**：被操控实体的字形以**白色**渲染（其余实体保持各自颜色），让你随时认出哪个是自己；观战时无高亮。

### 期四/期五回执（WebSocket 意图流已上线）

操控入口 `route_intents` 是独立路由层：来源从"终端键盘"换成"WebSocket 连接"只换了生产者，语义（意图流/操控优先/物理裁决）原样保留——点地走路、鼠标选目标、远程射击、登出处置都在同一意图模型上（见「五点七」）。**身份凭证升级（账号认证/网络登录进场）仍未开放**：me 声明目前仍是"本地文件/环境变量"，操控路由（声明 → 校验在线 → 操控）不变。

## 八、运行环境速查（部署/调参一页纸）

**启动**：`start.bat`（先检测旧进程占位再 build+run）。世界进程=终端画面+HTTP/WS 服务器二合一；关终端画面（q）世界照跑，关世界（Q 二次确认）自动存档。

**持久化**：世界每 100 拍存一次快照到 `codeworld.db`（SQLite），关闭时强制存档。重启自动恢复最新快照——**沙箱不持久化**：造物/玩家的代码与线性内存（含出生数据包）重启即失，恢复的旧实体只剩元数据（不跑代码的布景）；存储块（storage_write）与生存点数随实体入快照跨重启。在飞旧弹丸恢复时按哑弹清场。
